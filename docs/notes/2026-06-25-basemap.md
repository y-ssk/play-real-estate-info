# ベースマップ（地図下地）：選択肢とMapLibreへの導入 (2026-06-25)

> 採用＝`ADR-0019`（MVPは地理院淡色・将来Protomaps）。本メモは選択肢の整理と「どう入れるか」の蓄積。

## 学んだこと

### ベースマップとは
データ層（面塗り・重ね）の**下に敷く背景地図**（道路・地名・海岸線・地形）。MapLibre には下地のタイル/スタイルを与える必要がある。下地と我々のデータは別もので、MapLibre 上で重ねる。

### 選択肢
- **A. 地理院地図(GSI)タイル**：国土地理院の公式タイル。**淡色地図**はデータ重ね用の薄い下地。出典明示で無料・**トークン不要**・日本語・ops不要。ラスタが主（ベクトルタイルは実験的提供）。
- **B. 外部ベクタタイルサービス**（MapTiler/Stadia 等）：ベクタ下地＋スタイルが即。**要APIキー・外部依存・ToS・利用制限**。
- **C. 自前ホスト（Protomaps PMTiles）**：OSM由来のベクタ下地を**単一ファイル**で自前配信（Goが配れる・pmtilesプラグイン要）。MIT・無料・トークン不要・着色自由。ops増。
- **D. OSM生ラスタ直**：利用ポリシー違反で不可。

### MapLibre への導入の形（採用＝A）
**npm パッケージ不要**。自前 style（地図定義JSON）に GSI を**ラスタ source**として書くだけ。MapLibre core がラスタを描く。

```json
{
  "version": 8,
  "sources": {
    "gsi-pale": {
      "type": "raster",
      "tiles": ["https://cyberjapandata.gsi.go.jp/xyz/pale/{z}/{x}/{y}.png"],
      "tileSize": 256, "maxzoom": 18,
      "attribution": "<a href=\"https://www.gsi.go.jp/\">国土地理院</a>"
    }
  },
  "layers": [ { "id": "gsi-pale", "type": "raster", "source": "gsi-pale" } ]
}
```
- この style を react-map-gl の `<Map mapStyle={...}>` に渡す。
- `layers` 配列の**後ろ**に我々のデータ層（面塗り=`fill`／重ね=`circle`・`line`・`fill`）を足す＝下地の上に乗る（配列順＝重なり順）。
- **出典**は source の `attribution` を MapLibre が自動表示（`ADR-0011`）。
- **座標系**は GSI も Web メルカトル(3857)＝配信3857（`ADR-0014`）と一致。
- **直アクセス（MVP）→ Goプロキシ/キャッシュ（将来）** は style の `tiles` URL 差し替えだけ＝可逆（`docs/02` §1）。
- 対比：Protomaps（案C）は pmtiles 読み込みプラグインが要る。GSIラスタは不要＝MVP最薄。

## なぜ重要 / どこで効く
- `ADR-0013` のトークン不要・透明性、`ADR-0011` の出典、`ADR-0014` の3857 が、この導入形で一貫して効く。
- 下地はラスタでもデータ層はベクタのまま＝メッシュ戦略（`ADR-0015`）と両立。
- 正確なURL・最大ズーム・利用規約は実装着手時に公式確認（憶測しない）。
