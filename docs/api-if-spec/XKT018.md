# XKT018. 国土数値情報（市区町村役場及び集会施設等）API

> MLIT 不動産情報ライブラリ API の IF 定義（公式マニュアルからの生コピペを構造化したもの）。
> 転記のみ。原文で確認できない項目は「未確認」と明記。実装着手前に本書を最終確認する。

## 1. 概要
- 振り分け: タイル配信（`docs/02_architecture.md` 第3節。XKT 系=GISデータ→タイル配信。生活環境・周辺施設レイヤー）
- 形式: GISデータ（GeoJSON / バイナリベクトルタイル pbf）。XYZ タイル方式で取得
- 取得粒度: **施設の点（Point）**。タイル（z/x/y 指定。ズーム 13〜15）。属性フィルタ無し
- 内容: 市区町村役場・支所・行政サービス施設・集会施設等
- エンドポイント: `https://www.reinfolib.mlit.go.jp/ex-api/external/XKT018?<パラメータ>`
- 認証: ヘッダ `Ocp-Apim-Subscription-Key: <APIキー>`（キーは環境変数 `MLIT_API_KEY`。**AIは値に触れない**）
- エンコード: 原文に gzip/`--compressed` の記載なし（使用例にもオプションなし）。要確認
- 座標系: 出力例の CRS は `urn:ogc:def:crs:EPSG::6668`（JGD2011 地理座標系）

## 2. リクエストパラメータ
| パラメータ | 内容 | 形式 | 必須 | 備考 |
|---|---|---|---|---|
| response_format | 応答形式 | geojson / pbf | ○ | geojson…GeoJSON応答 / pbf…バイナリベクトルタイル応答 |
| z | ズームレベル（縮尺） | 整数 | ○ | 13（大字）〜15（詳細）で指定可能。値が大きいほど高ズーム |
| x | タイル座標のX値 | 整数 | ○ | XYZ方式のX値 |
| y | タイル座標のY値 | 整数 | ○ | XYZ方式のY値 |

制約（※注記）:
- XYZ方式の詳細は GSI の確認ツール参照。z は 13〜15。属性フィルタは無し。

## 3. レスポンス（出力）
包み構造: GeoJSON `FeatureCollection`（`name` は `city_town_hall`。`crs` は EPSG:6668）。`geometry.type` は `Point`。タグ命名は `P05_###` コード系。

各 Feature の `properties`（タグ）:

| タグ名 | 内容 | データ型 | データ例 | 備考 |
|---|---|---|---|---|
| P05_001 | 行政区域コード | 文字列型 | 13103 | 5桁 |
| P05_002 | 施設分類コード | 文字列型 | 5 | コード値。対応名称は `P05_002_name_ja`（観測: 2=支所/出張所/連絡所, 3=上記以外の行政サービス施設, 5=集会施設。全定義は原典参照・要確認） |
| P05_002_name_ja | 施設分類名 | 文字列型 | 集会施設 | `P05_002` の名称 |
| P05_003_ja | 名称 | 文字列型 | ありすいきいきプラザ | 施設名 |
| P05_004_ja | 所在地 | 文字列型 | 港区南麻布4-6-7 | |

- ※ 出力例の `properties` には IF表に無い内部フィールド **`_id`・`_index`（例: `bs009_city_town_hall_202403211538`）が含まれる**（要確認＝未文書・依存しない方が安全）。並び順は IF 表順と不一致（キー名参照が前提）。
- ※ 図書館（三田図書館）が `P05_002=5 集会施設` として含まれる例もあり、施設分類の粒度は粗い（XKT017 図書館 と重複し得る）。

## 4. 使用例
リクエスト（Windows コマンドプロンプト。GeoJSON取得）:
```
curl -H "Ocp-Apim-Subscription-Key:{発行されたAPIキー}" "https://www.reinfolib.mlit.go.jp/ex-api/external/XKT018?response_format=geojson&z=14&x=14551&y=6453" > XKT018.geojson
```
レスポンス例（GeoJSON。点データ。Feature 1件分を原文どおり。実際は多数）:
```
{
  "type": "FeatureCollection",
  "name": "city_town_hall",
  "crs": { "type": "name", "properties": { "name": "urn:ogc:def:crs:EPSG::6668" } },
  "features": [
    {
      "type": "Feature",
      "geometry": { "type": "Point", "coordinates": [139.72753286361694, 35.65108487698778] },
      "properties": {
        "_id": "Jtq7X44BOPXZiuqj8cK_",
        "_index": "bs009_city_town_hall_202403211538",
        "P05_001": "13103",
        "P05_002": "5",
        "P05_002_name_ja": "集会施設",
        "P05_003_ja": "ありすいきいきプラザ",
        "P05_004_ja": "港区南麻布4-6-7"
      }
    }
    /* features は多数（役場・支所・集会施設等の点） */
  ]
}
```
