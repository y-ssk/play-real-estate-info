## 2. リクエストパラメータ
| パラメータ | 内容 | 形式 | 必須 | 備考 |
|---|---|---|---|---|
| response_format | 応答形式 | geojson / pbf | ○ | geojson…GeoJSON応答 / pbf…バイナリベクトルタイル応答 |
| z | ズームレベル（縮尺） | 整数 | ○ | **13（大字）〜15（詳細）** で指定可能。値が大きいほど高ズーム（カバー領域は狭い）。※XKT026 は 14〜15 で範囲が異なる |
| x | タイル座標のX値 | 整数 | ○ | XYZ方式のX値 |
| y | タイル座標のY値 | 整数 | ○ | XYZ方式のY値 |

制約（※注記）:
- XYZ方式の詳細は GSI の確認ツール（上記参照URL）を参照。
- z は 13〜15 のみ指定可能。

## 3. レスポンス（出力）
包み構造: GeoJSON `FeatureCollection`（`response_format=geojson` の場合。例の `name` は `A49-21_24`）。`response_format=pbf` ではバイナリベクトルタイル。

各 Feature の `properties`（タグ。出力＜出力＞表より）:

| タグ名 | 内容 | データ型 | データ例 | 備考 |
|---|---|---|---|---|
| A49_001 | 都道府県名 | 文字列型 | 三重県 | |
| A49_002 | 都道府県コード | 文字列型 | 24 | |
| A49_003 | 浸水深区分 | 文字列型 | 5m以上10m未満 | 区分の文字列（XKT026 の浸水深ランク=整数とは表現が異なる） |
| target_year | 対象年 | 整数型 | 2021 | ※IF表には載るが、下記 GeoJSON 出力例の properties には **含まれていない**（要確認＝出力有無/条件） |

- ※ `geometry` は `Polygon`（外周＋穴の複数リングあり）。座標系は CRS（CRS84）。
- ※ XKT026 と異なり、出力例の properties に未文書フィールド（`_id`/`_index`）は見られない。

## 4. 使用例
リクエスト（Windows コマンドプロンプト。GeoJSON取得）:
```
curl -H "Ocp-Apim-Subscription-Key:{発行されたAPIキー}" "https://www.reinfolib.mlit.go.jp/ex-api/external/XKT027?response_format=geojson&z=13&x=7207&y=3258" > XKT027.geojson
```
レスポンス例（GeoJSON。座標列が膨大なため `coordinates` は中略。構造・CRS・properties は原文どおり）:
```
{
  "type": "FeatureCollection",
  "name": "A49-21_24",
  "crs": {
    "type": "name",
    "properties": {
      "name": "urn:ogc:def:crs:OGC:1.3:CRS84"
    }
  },
  "features": [
    {
      "type": "Feature",
      "properties": {
        "A49_001": "三重県",
        "A49_002": "24",
        "A49_003": "5m以上10m未満"
      },
      "geometry": {
        "type": "Polygon",
        "coordinates": [
          [ [136.73892095148798, 34.5078728517301], [136.7390298485695, 34.507872193013746], ... ],
          [ [136.73783913106377, 34.50869075796309], [136.73783833654022, 34.50860061081211], ... ]
        ]
        /* ↑ 実際は数百〜の座標ペア・複数リング。原典は分割提供あり（概要の注記参照） */
      }
    }
  ]
}
```
