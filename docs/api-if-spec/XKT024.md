# XKT024. 都市計画決定GISデータ（高度利用地区）API

## 1. 概要
- 提供元: 都市計画決定GISデータ（XKT023 と同型サブファミリ＝`group_code`/`kubun_id`文字列/`decision_type_ja`）
- 振り分け: タイル配信（`docs/02_architecture.md` 第3節。XKT 系=GISデータ→タイル配信。規制・都市計画レイヤー）
- 形式: GISデータ（GeoJSON / バイナリベクトルタイル pbf）。XYZ タイル方式で取得
- 取得粒度: 高度利用地区の区域ポリゴン。タイル（z/x/y 指定。ズーム 11〜15）。属性フィルタ無し
- 内容: 都市計画の**高度利用地区**（容積率の最高限度/最低限度等で土地の高度利用を促す地区。地区固有名を持つ）
- エンドポイント: `https://www.reinfolib.mlit.go.jp/ex-api/external/XKT024?<パラメータ>`
- 認証: ヘッダ `Ocp-Apim-Subscription-Key: <APIキー>`（キーは環境変数 `MLIT_API_KEY`。**AIは値に触れない**）
- エンコード: 原文に gzip/`--compressed` の記載なし（使用例にもオプションなし）。要確認
- 座標系: 出力例の CRS は `urn:ogc:def:crs:EPSG::6668`（JGD2011 地理座標系）

## 2. リクエストパラメータ
| パラメータ | 内容 | 形式 | 必須 | 備考 |
|---|---|---|---|---|
| response_format | 応答形式 | geojson / pbf | ○ | geojson…GeoJSON応答 / pbf…バイナリベクトルタイル応答 |
| z | ズームレベル（縮尺） | 整数 | ○ | 11（市）〜15（詳細）で指定可能。値が大きいほど高ズーム |
| x | タイル座標のX値 | 整数 | ○ | XYZ方式のX値 |
| y | タイル座標のY値 | 整数 | ○ | XYZ方式のY値 |

制約（※注記）:
- XYZ方式の詳細は GSI の確認ツール参照。z は 11〜15。属性フィルタは無し。

## 3. レスポンス（出力）
包み構造: GeoJSON `FeatureCollection`（`name` は `advanced_use`。`crs` は EPSG:6668）。`geometry.type` は `Polygon`（出力例）。タグ命名は説明的 snake_case。
- XKT023 と同じく `group_code`（行政コード）・`kubun_id`（文字列型）・`decision_type_ja`（設定区分名）を用いる系統。

各 Feature の `properties`（タグ）:

| タグ名 | 内容 | データ型 | データ例 | 備考 |
|---|---|---|---|---|
| advanced_name | 高度名称 | 文字列型 | 平河町二丁目東部南地区高度利用地区 | 地区固有名 |
| advanced_type_ja | 高度区分名 | 文字列型 | 高度利用地区 | |
| kubun_id | 区分コード | 文字列型 | 19 | **文字列型**（XKT023 と同様）。定義は原典参照・要確認 |
| group_code | 行政コード | 文字列型 | 13101 | 5桁（他APIの `city_code` 相当） |
| decision_date | 設定年月日 | 文字列型 | 平成18年2月23日 | **和暦**（最終告示日） |
| decision_type_ja | 設定区分名 | 文字列型 | 高度利用地区 | （本APIでは値あり） |
| decision_maker | 設定者名 | 文字列型 | （空） | |
| notice_number | 告示番号 | 文字列型 | 区告第26号 | 告示番号L（告示番号（最終）） |
| prefecture | 都道府県名 | 文字列型 | 東京都 | |
| city_name | 市町村名 | 文字列型 | 千代田区 | |
| first_decision_date | 当初決定日 | 文字列型 | （空） | |
| notice_number_s | 告示番号S | 文字列型 | （空） | 告示番号（当初） |

- ※ 出力例の `properties` には IF表に無い内部フィールド **`_id`・`_index`（例: `bs026_advanced_use_202508211131`）が含まれる**（要確認＝未文書・依存しない方が安全）。並び順は IF 表順と不一致（キー名参照が前提）。

## 4. 使用例
リクエスト（Windows コマンドプロンプト。GeoJSON取得）:
```
curl -H "Ocp-Apim-Subscription-Key:{発行されたAPIキー}" "https://www.reinfolib.mlit.go.jp/ex-api/external/XKT024?response_format=geojson&z=14&x=14551&y=6451" > XKT024.geojson
```
