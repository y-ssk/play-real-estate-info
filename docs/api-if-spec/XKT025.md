## 2. リクエストパラメータ
| パラメータ | 内容 | 形式 | 必須 | 備考 |
|---|---|---|---|---|
| response_format | 応答形式 | geojson / pbf | ○ | geojson…GeoJSON応答 / pbf…バイナリベクトルタイル応答 |
| z | ズームレベル（縮尺） | 整数 | ○ | 11（市）〜15（詳細）で指定可能。値が大きいほど高ズーム（カバー領域は狭い） |
| x | タイル座標のX値 | 整数 | ○ | XYZ方式のX値 |
| y | タイル座標のY値 | 整数 | ○ | XYZ方式のY値 |

制約（※注記）:
- XYZ方式の詳細は GSI の確認ツール（上記参照URL）を参照。
- z は 11〜15 で指定可能。属性フィルタは無し。

## 3. レスポンス（出力）
包み構造: GeoJSON `FeatureCollection`（`response_format=geojson` の場合。例の `name` は `liquefaction_tendency_map`）。`response_format=pbf` ではバイナリベクトルタイル。
- `geometry.type` は `Polygon`（出力例は規則的なメッシュ矩形＝`mesh_code` 単位の区画）。
- タグ命名は説明的 snake_case。**メッシュコードを主キー的に持つ**点が、市区町村コード系の他レイヤーと異なる。

各 Feature の `properties`（タグ）:

| タグ名 | 内容 | データ型 | データ例 | 備考 |
|---|---|---|---|---|
| mesh_code | メッシュコード | 文字列型 | 5339359931 | 10桁。標準地域メッシュの細分（粒度＝原典参照・未確認） |
| topographic_classification_code | 微地形区分（28区分） | 整数型 | 9 | コード値（全28区分）。対応名称は `topographic_classification_name_ja` |
| topographic_classification_name_ja | 微地形区分の名称 | 文字列型 | ローム台地 | `..._code` の名称（凡例インライン）。`_ja` サフィックス |
| liquefaction_tendency_level | 液状化発生傾向の強弱（6段階区分） | 整数型 | 5 | 6段階のレベル値。値→強弱の対応は原典参照（`note` が説明文を持つ） |
| note | 説明 | 文字列型 | 液状化しにくい | `liquefaction_tendency_level` に対応する説明文 |

- ※ 出力例の `properties` には上記に加え、IF表に無い内部フィールド **`_id`・`_index`（例: `bs028_liquefaction_tendency_map_202410101023`）が含まれる**（防災系共通。要確認＝未文書・依存しない方が安全）。並び順は IF 表順と不一致（キー名参照が前提）。

## 4. 使用例
リクエスト（Windows コマンドプロンプト。GeoJSON取得）:
```
curl -H "Ocp-Apim-Subscription-Key:{発行されたAPIキー}" "https://www.reinfolib.mlit.go.jp/ex-api/external/XKT025?response_format=geojson&z=15&x=29103&y=12905" > XKT025.geojson
```
