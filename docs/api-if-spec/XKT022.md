# XKT022. 国土数値情報（急傾斜地崩壊危険区域）API

> MLIT 不動産情報ライブラリ API の IF 定義（公式マニュアルからの生コピペを構造化したもの）。
> 転記のみ。原文で確認できない項目は「未確認」と明記。実装着手前に本書を最終確認する。

## 1. 概要
- 振り分け: タイル配信（`docs/02_architecture.md` 第3節。XKT 系=GISデータ→多くがタイル配信。防災コアの一枚）
- 形式: GISデータ（GeoJSON / バイナリベクトルタイル pbf）。XYZ タイル方式で取得
- 取得粒度: タイル（z/x/y 指定。ズーム 11〜15）。**加えて `prefectureCode` / `administrativeAreaCode` で絞り込み可**（XKT021 と同構成）
- エンドポイント: `https://www.reinfolib.mlit.go.jp/ex-api/external/XKT022?<パラメータ>`
- 認証: ヘッダ `Ocp-Apim-Subscription-Key: <APIキー>`（キーは環境変数 `MLIT_API_KEY`。**AIは値に触れない**）
- エンコード: 原文に gzip/`--compressed` の記載なし（使用例にもオプションなし）。要確認
- 座標系: 出力例の CRS は `urn:ogc:def:crs:EPSG::6668`（JGD2011 地理座標系。防災系の多くと同じ）

## 2. リクエストパラメータ
| パラメータ | 内容 | 形式 | 必須 | 備考 |
|---|---|---|---|---|
| response_format | 応答形式 | geojson / pbf | ○ | geojson…GeoJSON応答 / pbf…バイナリベクトルタイル応答 |
| z | ズームレベル（縮尺） | 整数 | ○ | 11（市）〜15（詳細）で指定可能。値が大きいほど高ズーム（カバー領域は狭い） |
| x | タイル座標のX値 | 整数 | ○ | XYZ方式のX値 |
| y | タイル座標のY値 | 整数 | ○ | XYZ方式のY値 |
| prefectureCode | 都道府県コード | NN（数字2桁） | （任意。原文の必須欄は空） | 複数指定はカンマ区切り（例: `prefectureCode=09,14`）。PrefCd.html 参照 |
| administrativeAreaCode | 行政コード | NNNNN（数字5桁） | （任意。原文の必須欄は空） | 複数指定はカンマ区切り（例: `administrativeAreaCode=01101,13102`）。AdminiBoundary_CD.xlsx 参照 |

制約（※注記）:
- XYZ方式の詳細は GSI の確認ツール（上記参照URL）を参照。
- z は 11〜15 で指定可能。
- `prefectureCode` / `administrativeAreaCode` の必須/任意は原文の必須欄が空のため**任意と判断**（要確認）。併用可否も未確認。

## 3. レスポンス（出力）
包み構造: GeoJSON `FeatureCollection`（`response_format=geojson` の場合。例の `name` は `collapse_risk_area`）。`response_format=pbf` ではバイナリベクトルタイル。
- タグ命名は XKT021 と同じく説明的 snake_case（`A##_###` コード系とは別）。ただし日付/番号のキー名は XKT021 と微妙に異なる（下表参照）。

各 Feature の `properties`（タグ）:

| タグ名 | 内容 | データ型 | データ例 | 備考 |
|---|---|---|---|---|
| prefecture_code | 都道府県コード | 文字列型 | 14 | |
| group_code | 行政コード | 文字列型 | 14201 | リクエストの `administrativeAreaCode` に対応 |
| city_name | 市町村名 | 文字列型 | 横須賀市 | |
| region_name | 区域名 | 文字列型 | 佐島B | |
| address | 所在地 | 文字列型 | 横須賀市佐島 | |
| public_notice_date | 公示年月日 | 文字列型 | 1984/03/31 | `YYYY/MM/DD`。※XKT021 は `notice_date`＝**キー名が異なる** |
| public_notice_number | 公示番号 | 文字列型 | 第320号 | ※XKT021 は `notice_number` で値も `579`（こちらは「第…号」表記）＝**キー名・値表記とも差** |
| landslide_area | 指定面積（ha） | 文字列型 | 2.6(ha) | 単位込み文字列（XKT021 と同形式。値は非ゼロ実値の例） |
| prefecture_name | 都道府県名 | 文字列型 | 神奈川県 | |

- ※ XKT021 にあった `charge_ministry_code` / `charge_ministry_name`（所管省庁）は**本APIには無い**。
- ※ 出力例の `properties` には上記に加え、IF表に無い内部フィールド **`_id`・`_index`（例: `bs025_collapse_risk_area_202412161234`）が含まれる**（防災系共通。要確認＝未文書・依存しない方が安全）。並び順は IF 表順と不一致（キー名参照が前提）。

## 4. 使用例
リクエスト（Windows コマンドプロンプト。GeoJSON取得）:
```
curl -H "Ocp-Apim-Subscription-Key:{発行されたAPIキー}" "https://www.reinfolib.mlit.go.jp/ex-api/external/XKT022?response_format=geojson&z=14&x=14545&y=6477" > XKT022.geojson
```
