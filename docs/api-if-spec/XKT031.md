# XKT031. 国土数値情報（人口集中地区）API

> MLIT 不動産情報ライブラリ API の IF 定義（公式マニュアルからの生コピペを構造化したもの）。
> 転記のみ。原文で確認できない項目は「未確認」と明記。実装着手前に本書を最終確認する。

## 1. 概要
- 振り分け: タイル配信（`docs/02_architecture.md` 第3節。XKT 系=GISデータ→タイル配信）。市区町村単位の集約度指標として ETL/両用の余地
- 形式: GISデータ（GeoJSON / バイナリベクトルタイル pbf）。XYZ タイル方式で取得
- 取得粒度: **人口集中地区（DID）単位のポリゴン**。タイル（z/x/y。ズーム 9〜15）＋ `administrativeAreaCode` で絞り込み
- 内容: 国勢調査の人口集中地区（DID）。人口・面積・前回値・全域に占める割合・男女別・世帯数。「街の市街地度/集約度」を表す
- エンドポイント: `https://www.reinfolib.mlit.go.jp/ex-api/external/XKT031?<パラメータ>`
- 認証: ヘッダ `Ocp-Apim-Subscription-Key: <APIキー>`（キーは環境変数 `MLIT_API_KEY`。**AIは値に触れない**）
- エンコード: 原文に gzip/`--compressed` の記載なし（使用例にもオプションなし）。要確認
- 座標系: 出力例の CRS は `urn:ogc:def:crs:EPSG::6668`（JGD2011 地理座標系）

## 2. リクエストパラメータ
| パラメータ | 内容 | 形式 | 必須 | 備考 |
|---|---|---|---|---|
| response_format | 応答形式 | geojson / pbf | ○ | geojson…GeoJSON応答 / pbf…バイナリベクトルタイル応答 |
| z | ズームレベル（縮尺） | 整数 | ○ | **9（都道府県）〜15（詳細）** で指定可能。値が大きいほど高ズーム |
| x | タイル座標のX値 | 整数 | ○ | XYZ方式のX値 |
| y | タイル座標のY値 | 整数 | ○ | XYZ方式のY値 |
| administrativeAreaCode | 行政区域コード | NNNNN（数字5桁） | （任意。原文の必須欄は空） | 複数指定はカンマ区切り（例: `administrativeAreaCode=01101,13102`）。AdminiBoundary_CD.xlsx 参照 |

制約（※注記）:
- XYZ方式の詳細は GSI の確認ツール参照。z は 9〜15。
- `administrativeAreaCode` の必須/任意は原文の必須欄が空のため**任意と判断**（要確認）。

## 3. レスポンス（出力）
包み構造: GeoJSON `FeatureCollection`（`name` は `densely_inhabited_district`、`crs` は EPSG:6668）。`geometry.type` は `MultiPolygon`（DID 区域）。
- タグ命名は `A16_###` コード系（防災 XKT016/026 系と同系統）。**型が明快に分かれている**（文字列/整数/実数）＝価格・防災の文字列偏重と異なり数値で扱いやすい。

各 Feature の `properties`（タグ）:

|---|---|---|---|---|

| A16_002 | 行政区域コード | 文字列型 | 40213 | 5桁。リクエストの `administrativeAreaCode` に対応 |
| A16_003 | 市区町村名称 | 文字列型 | 行橋市 | |
| A16_004 | 人口集中地区符合 | 整数型 | 1 | コード/区分（意味は原典参照・要確認） |
| A16_005 | 人口 | 整数型 | 29624 | 当年（A16_011 の調査年度） |

```

```

## 5. MachiLens 取り込み観点（実装・レビューの足場）
> 着手段階で AI が記入する欄。空欄は「未検討」。人口・需要＝「街の素性」指標。
- 振り分け方針: タイル＋ETL/両用が有力。**A16_009（DID人口割合）＝市街地度、A16_005/006＝規模、前回比（A16_005 vs A16_007）＝集約の増減**が市区町村の素性指標に直結。XKT013（将来推計）と合わせ「人口の現在と将来」を構成。
- 取り込み対象フィールド / PostGIS マッピング: 未検討（`A16_002`＝市区町村結合キー、`MultiPolygon`。数値型が明快で集計しやすい）
- 一意キー（冪等性の判定キー）: 未検討（候補: `A16_001` DIDid。1市区町村に複数DIDあり得るため DID単位が妥当）
- 値域・整合チェック（層1）: 未検討（人口/世帯は非負整数、面積は正の実数、A16_012+A16_013≒A16_005、A16_009/010 は0〜100%、A16_002 5桁、A16_011 年度の妥当性）
- 欠損の扱い（"データなし" の判定と UI 表示への接続）: 未検討（features 空＝DIDなし＝非市街地。前回値が無い新設DIDの扱い）
- 出典の保持（MLIT 出典の紐づけ＝法的要件）: 未検討（国土数値情報・国勢調査）
- レート制御メモ（連続実行を避ける）: 未検討（z=9 から取得可で広域は粗ズームで件数を抑えられる）
- 未確認・要確認事項:
  - 転記元の公式ドキュメント URL／「原典データ項目」詳細ページ URL
  - gzip エンコードの要否（原文に記載なし）
  - `A16_004` 人口集中地区符合 のコード定義
