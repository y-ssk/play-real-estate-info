## 1. 概要
- 提供元: 都市計画決定GISデータ（XKT001/002/003 と同系統）
- 振り分け: タイル配信（`docs/02_architecture.md` 第3節。XKT 系=GISデータ→タイル配信。規制・都市計画レイヤー）
- 形式: GISデータ（GeoJSON / バイナリベクトルタイル pbf）。XYZ タイル方式で取得
- 取得粒度: 区域ポリゴン。タイル（z/x/y 指定。ズーム 11〜15）。属性フィルタ無し
- 内容: 都市計画の**防火地域・準防火地域**（建築制限に関わる）。防災コア（災害リスク）とは別軸の規制情報
- エンドポイント: `https://www.reinfolib.mlit.go.jp/ex-api/external/XKT014?<パラメータ>`
- 認証: ヘッダ `Ocp-Apim-Subscription-Key: <APIキー>`（キーは環境変数 `MLIT_API_KEY`。**AIは値に触れない**）
- エンコード: 原文に gzip/`--compressed` の記載なし（使用例にもオプションなし）。要確認
- 座標系: 出力例の CRS は `urn:ogc:def:crs:EPSG::6668`（JGD2011 地理座標系）

## 2. リクエストパラメータ
| パラメータ | 内容 | 形式 | 必須 | 備考 |
|---|---|---|---|---|
| response_format | 応答形式 | geojson / pbf | ○ | geojson…GeoJSON応答 / pbf…バイナリベクトルタイル応答 |
| z | ズームレベル（縮尺） | 整数 | ○ | 11（市）〜15（詳細）で指定可能。値が大きいほど高ズーム |
| x | タイル座標のX値 | 整数 | ○ | XYZ方式のX値 |
| y | タイル座標のY値 | 整数 | ○ | XYZ方式のY値 |

制約（※注記）:
- XYZ方式の詳細は GSI の確認ツール参照。z は 11〜15。属性フィルタは無し。

## 3. レスポンス（出力）
包み構造: GeoJSON `FeatureCollection`（`name` は `fire_protection_area`。`crs` は EPSG:6668）。
- `geometry.type` は **`Polygon` と `MultiPolygon` が混在**。タグ命名は説明的 snake_case。
- **本APIは告示・決定系フィールドが記入されている**（XKT001/002/003 は空多数だった。整備状況はAPI/地域で差）。

各 Feature の `properties`（タグ）:

| タグ名 | 内容 | データ型 | データ例 | 備考 |
|---|---|---|---|---|
| fire_prevention_ja | 防火・準防火地域名 | 文字列型 | 準防火地域 | `kubun_id` の名称 |
| kubun_id | 区分コード | 整数型 | 25 | コード値（観測: 25=準防火地域 / 24=防火地域。全定義は原典参照・要確認） |
| prefecture | 都道府県名 | 文字列型 | 神奈川県 | |
| city_code | 市区町村コード | 文字列型 | 14201 | 5桁 |
| city_name | 市区町村名 | 文字列型 | 横須賀市 | |
| decision_date | 設定年月日 | 文字列型 | 令和3年2月25日 | **和暦表記**（最終告示日。XPT002 と同系の和暦。XKT016 の ISO 等と不統一） |
| decision_classification | 設定区分 | 文字列型 | （空） | |
| decision_maker | 設定者名 | 文字列型 | （空） | |
| notice_number | 告示番号 | 文字列型 | 市告示第29号 | 告示番号L（告示番号（最終）） |
| first_decision_date | 当初決定日 | 文字列型 | （空） | |
| notice_number_s | 告示番号S | 文字列型 | （空） | 告示番号（当初） |

- ※ 出力例の `properties` には IF表に無い内部フィールド **`_id`・`_index`（例: `bs002_fire_protection_area_202508211101`）が含まれる**（要確認＝未文書・依存しない方が安全）。並び順は IF 表順と不一致（キー名参照が前提）。

## 4. 使用例
リクエスト（Windows コマンドプロンプト。GeoJSON取得）:
```
curl -H "Ocp-Apim-Subscription-Key:{発行されたAPIキー}" "https://www.reinfolib.mlit.go.jp/ex-api/external/XKT014?response_format=geojson&z=15&x=29096&y=12948" > XKT014.geojson
```
