## 1. 概要
- 提供元: 都市計画決定GISデータ（XKT001 と同系統。国土数値情報とは別出典表記）
- 振り分け: タイル配信（`docs/02_architecture.md` 第3節。XKT 系=GISデータ→タイル配信。規制・都市計画レイヤー）
- 形式: GISデータ（GeoJSON / バイナリベクトルタイル pbf）。XYZ タイル方式で取得
- 取得粒度: 用途地域ポリゴン。タイル（z/x/y 指定。ズーム 11〜15）。属性フィルタ無し
- 内容: 都市計画の**用途地域**（準工業地域・工業専用地域 等）と、それに紐づく**容積率・建蔽率**。`docs/02`§3 規制・都市計画。住み替え判断に直結
- エンドポイント: `https://www.reinfolib.mlit.go.jp/ex-api/external/XKT002?<パラメータ>`
- 認証: ヘッダ `Ocp-Apim-Subscription-Key: <APIキー>`（キーは環境変数 `MLIT_API_KEY`。**AIは値に触れない**）
- エンコード: 原文に gzip/`--compressed` の記載なし（使用例にもオプションなし）。要確認
- 座標系: 出力例の CRS は `urn:ogc:def:crs:EPSG::6668`（JGD2011 地理座標系）

## 2. リクエストパラメータ
| パラメータ | 内容 | 形式 | 必須 | 備考 |
|---|---|---|---|---|
| response_format | 応答形式 | geojson / pbf | ○ | geojson…GeoJSON応答 / pbf…バイナリベクトルタイル応答 |
| z | ズームレベル（縮尺） | 整数 | ○ | 11（市）〜15（詳細）で指定可能。値が大きいほど高ズーム |
| x | タイル座標のX値 | 整数 | ○ | XYZ方式のX値 |
| y | タイル座標のY値 | 整数 | ○ | XYZ方式のY値 |

制約（※注記）:
- XYZ方式の詳細は GSI の確認ツール参照。z は 11〜15。属性フィルタは無し。

## 3. レスポンス（出力）
包み構造: GeoJSON `FeatureCollection`（`name` は `use_area`。XKT001 のような複合ではなく単一データセット）。`crs` は EPSG:6668。
- `geometry.type` は `Polygon`（出力例）。タグ命名は説明的 snake_case。
- 告示・決定系フィールドは出力例ではほぼ空（XKT001 と同傾向）。

各 Feature の `properties`（タグ）:

| タグ名 | 内容 | データ型 | データ例 | 備考 |
|---|---|---|---|---|
| youto_id | 用途地域分類 | 整数型 | 11 | コード値（観測: 11=準工業地域 / 13=工業専用地域。全定義は原典参照・要確認） |
| prefecture | 都道府県名 | 文字列型 | 兵庫県 | |
| city_code | 市区町村コード | 文字列型 | 28100 | 5桁 |
| city_name | 市区町村名 | 文字列型 | 神戸市 | |
| decision_date | 区域設定年月日 | 文字列型 | （空） | 最終告示日 |
| decision_classification | 設定区分 | 文字列型 | （空） | |
| decision_maker | 設定者名 | 文字列型 | （空） | |
| notice_number | 告示番号 | 文字列型 | （空） | 告示番号L（告示番号（最終）） |
| use_area_ja | 用途地域名 | 文字列型 | 準工業地域 | `youto_id` の名称 |
| u_floor_area_ratio_ja | 容積率 | 文字列型 | 300% | **%付き整形文字列**（要パース） |
| u_building_coverage_ratio_ja | 建蔽率 | 文字列型 | 80% | **%付き整形文字列**（要パース） |
| first_decision_date | 当初決定日 | 文字列型 | （空） | |
| notice_number_s | 告示番号S | 文字列型 | （空） | 告示番号（当初） |

- ※ 出力例の `properties` には IF表に無い内部フィールド **`_id`・`_index`（例: `bs001_use_area_202511181133`）が含まれる**（要確認＝未文書・依存しない方が安全）。並び順は IF 表順と不一致（キー名参照が前提）。
- ※ `use_area_ja` と `youto_id` は対応（凡例インライン）。容積率/建蔽率は用途地域に紐づくが、同一用途地域名でも地区により異なる値を取り得る点に注意。

## 4. 使用例
リクエスト（Windows コマンドプロンプト。GeoJSON取得）:
```
curl -H "Ocp-Apim-Subscription-Key:{発行されたAPIキー}" "https://www.reinfolib.mlit.go.jp/ex-api/external/XKT002?response_format=geojson&z=14&x=14339&y=6505" > XKT002.geojson
```
レスポンス例（GeoJSON。座標列が膨大なため `coordinates` は中略。構造・CRS・properties は原文どおり、Feature 1件分を示す）:
```

  "crs": { "type": "name", "properties": { "name": "urn:ogc:def:crs:EPSG::6668" } },

    {

      "geometry": { "type": "Polygon", "coordinates": [ [ [135.0843608379364, 34.72357697238161], ... ] ] },

        "_index": "bs001_use_area_202511181133",
        "prefecture": "兵庫県",

        "city_name": "神戸市",
```
