## 2. リクエストパラメータ
| パラメータ | 内容 | 形式 | 必須 | 備考 |
|---|---|---|---|---|
| response_format | 応答形式 | geojson / pbf | ○ | geojson…GeoJSON応答 / pbf…バイナリベクトルタイル応答 |
| z | ズームレベル（縮尺） | 整数 | ○ | 14（丁目）〜15（詳細）で指定可能。値が大きいほど高ズーム（カバー領域は狭い） |
| x | タイル座標のX値 | 整数 | ○ | XYZ方式のX値 |
| y | タイル座標のY値 | 整数 | ○ | XYZ方式のY値 |

制約（※注記）:
- XYZ方式の詳細は GSI の確認ツール（上記参照URL）を参照。
- z は 14〜15 のみ指定可能。

## 3. レスポンス（出力）
包み構造: GeoJSON `FeatureCollection`（`response_format=geojson` の場合。例の `name` は `tsunami_area`）。`response_format=pbf` ではバイナリベクトルタイル。

各 Feature の `properties`（タグ）:

| タグ名 | 内容 | データ型 | データ例 | 備考 |
|---|---|---|---|---|
| A40_001 | 都道府県名 | 文字列型 | 東京都 | |
| A40_002 | 都道府県コード | 文字列型 | 13 | |
| A40_003 | 津波浸水深の区分 | 文字列型 | 3m以上 〜 5m未満 | 区分の文字列（XKT026 の整数ランクとは表現が異なる。XKT027 A49_003 と同系） |
| target_year | 対象年 | 整数型 | 2023 | 本APIでは出力例の properties に**存在**（XKT027 の出力例には無かった項目。API差あり） |

- ※ 出力例の `properties` には上記に加え、IF表に無い内部フィールド **`_id`（例: `ndfbX5kBiyIAKTI7ohBX`）・`_index`（例: `bs032_tsunami_area_202509191144`）が含まれる**（XKT026 と同様。要確認＝未文書・依存しない方が安全）。
- ※ `geometry` は `Polygon`（複数リングあり）。座標系は CRS（EPSG:6668）。

## 4. 使用例
リクエスト（Windows コマンドプロンプト。GeoJSON取得）:
```
curl -H "Ocp-Apim-Subscription-Key:{発行されたAPIキー}" "https://www.reinfolib.mlit.go.jp/ex-api/external/XKT028?response_format=geojson&z=14&x=14535&y=6501" > XKT028.geojson
```
