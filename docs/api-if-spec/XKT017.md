## 1. 概要
- 振り分け: タイル配信（`docs/02_architecture.md` 第3節。XKT 系=GISデータ→タイル配信。生活環境・周辺施設レイヤー）
- 形式: GISデータ（GeoJSON / バイナリベクトルタイル pbf）。XYZ タイル方式で取得
- 取得粒度: **施設の点（Point）**。タイル（z/x/y 指定。ズーム 13〜15）＋ `administrativeAreaCode` で絞り込み
- 内容: 図書館（文化施設の一種）。建築年・階数も持つ
- エンドポイント: `https://www.reinfolib.mlit.go.jp/ex-api/external/XKT017?<パラメータ>`
- 認証: ヘッダ `Ocp-Apim-Subscription-Key: <APIキー>`（キーは環境変数 `MLIT_API_KEY`。**AIは値に触れない**）
- エンコード: 原文に gzip/`--compressed` の記載なし（使用例にもオプションなし）。要確認
- 座標系: 出力例の CRS は **`urn:ogc:def:crs:EPSG::4612`（JGD2000）**。＝**他の多くのレイヤー（EPSG:6668＝JGD2011）と異なる**（XKT027 の CRS84 に続く不統一。取り込み時に正規化要）

## 2. リクエストパラメータ
| パラメータ | 内容 | 形式 | 必須 | 備考 |
|---|---|---|---|---|
| response_format | 応答形式 | geojson / pbf | ○ | geojson…GeoJSON応答 / pbf…バイナリベクトルタイル応答 |
| z | ズームレベル（縮尺） | 整数 | ○ | 13（大字）〜15（詳細）で指定可能。値が大きいほど高ズーム |
| x | タイル座標のX値 | 整数 | ○ | XYZ方式のX値 |
| y | タイル座標のY値 | 整数 | ○ | XYZ方式のY値 |
| administrativeAreaCode | 行政区域コード | NNNNN（数字5桁） | （任意。原文の必須欄は空） | 複数指定はカンマ区切り（例: `administrativeAreaCode=01101,13102`）。AdminiBoundary_CD.xlsx 参照 |

制約（※注記）:
- XYZ方式の詳細は GSI の確認ツール参照。z は 13〜15。
- `administrativeAreaCode` の必須/任意は原文の必須欄が空のため**任意と判断**（要確認）。

## 3. レスポンス（出力）
包み構造: GeoJSON `FeatureCollection`（`name` は `cultural_facility`＝図書館は文化施設の一種として配信。`crs` は **EPSG:4612**）。`geometry.type` は `Point`。タグ命名は `P27_###` コード系。

各 Feature の `properties`（タグ）:

| タグ名 | 内容 | データ型 | データ例 | 備考 |
|---|---|---|---|---|
| P27_001 | 行政区域コード | 文字列型 | 01103 | 5桁 |
| P27_002 | 公共施設大分類 | 文字列型 | 3 | コード値（定義は原典参照・要確認） |
| P27_003 | 公共施設小分類 | 文字列型 | 03003 | コード値。対応名称は `P27_003_name_ja` |
| P27_003_name_ja | 公共施設小分類名 | 文字列型 | 図書館 | `P27_003` の名称 |
| P27_004 | 文化施設分類 | 文字列型 | 03003 | コード値。対応名称は `P27_004_name_ja`（例では `P27_003` と同値） |
| P27_004_name_ja | 文化施設分類名 | 文字列型 | 図書館 | `P27_004` の名称 |
| P27_005_ja | 名称 | 文字列型 | 札幌市元町図書館 | 施設名 |
| P27_006_ja | 所在地 | 文字列型 | 北30条東16-3-13 | |
| P27_007 | 管理者コード | 整数型 | 3 | コード値（定義は原典参照・要確認） |
| P27_008 | 階数 | 整数型 | 2 | 建物の階数 |
| P27_009 | 建築年 | 整数型 | 1984 | 西暦4桁 |

- ※ 出力例の `properties` には IF表に無い内部フィールド **`_id`・`_index`（例: `bs020_cultural_facility_202403211848`）が含まれる**（要確認＝未文書・依存しない方が安全）。並び順は IF 表順と不一致（キー名参照が前提）。

## 4. 使用例
リクエスト（Windows コマンドプロンプト。GeoJSON取得）:
```
curl -H "Ocp-Apim-Subscription-Key:{発行されたAPIキー}" "https://www.reinfolib.mlit.go.jp/ex-api/external/XKT017?response_format=geojson&z=13&x=7312&y=3007" > XKT017.geojson
```
レスポンス例（GeoJSON。点データ。Feature 1件分を原文どおり。CRS が EPSG:4612 である点に注意）:
