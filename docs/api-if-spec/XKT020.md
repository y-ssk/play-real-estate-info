## 1. 概要
- 振り分け: タイル配信（`docs/02_architecture.md` 第3節。XKT 系=GISデータ→多くがタイル配信。防災コアの一枚）
- 形式: GISデータ（GeoJSON / バイナリベクトルタイル pbf）。XYZ タイル方式で取得
- 取得粒度: タイル（z/x/y 指定。ズーム 11〜15）。**属性フィルタ無し**（z/x/y のみ。XKT016/021/022 と異なり prefectureCode 等を持たない）
- エンドポイント: `https://www.reinfolib.mlit.go.jp/ex-api/external/XKT020?<パラメータ>`
- 認証: ヘッダ `Ocp-Apim-Subscription-Key: <APIキー>`（キーは環境変数 `MLIT_API_KEY`。**AIは値に触れない**）
- エンコード: 原文に gzip/`--compressed` の記載なし（使用例にもオプションなし）。要確認
- 座標系: 出力例の CRS は `urn:ogc:def:crs:EPSG::6668`（JGD2011 地理座標系。防災系の多くと同じ）

## 2. リクエストパラメータ
| パラメータ | 内容 | 形式 | 必須 | 備考 |
|---|---|---|---|---|
| response_format | 応答形式 | geojson / pbf | ○ | geojson…GeoJSON応答 / pbf…バイナリベクトルタイル応答 |
| z | ズームレベル（縮尺） | 整数 | ○ | 11（市）〜15（詳細）で指定可能。値が大きいほど高ズーム（カバー領域は狭い） |
| x | タイル座標のX値 | 整数 | ○ | XYZ方式のX値 |
| y | タイル座標のY値 | 整数 | ○ | XYZ方式のY値 |

制約（※注記）:
- XYZ方式の詳細は GSI の確認ツール（上記参照URL）を参照。
- z は 11〜15 で指定可能。
- 属性フィルタ（prefectureCode / administrativeAreaCode 等）は無し。

## 3. レスポンス（出力）
包み構造: GeoJSON `FeatureCollection`（`response_format=geojson` の場合。例の `name` は `developed_land`）。`response_format=pbf` ではバイナリベクトルタイル。
- **`geometry.type` に `Polygon` と `MultiPolygon` が混在**（出力例の1件目=Polygon、2件目=MultiPolygon）。＝取り込み/描画でマルチジオメトリ対応が必要。
- タグ命名は説明的 snake_case。ただし市区町村コードのキーが **`city_code`**（XKT021/022 は `group_code`、XIT001 は `MunicipalityCode`）＝レイヤー間でキー名がさらに揺れる。

各 Feature の `properties`（タグ）:

| タグ名 | 内容 | データ型 | データ例 | 備考 |
|---|---|---|---|---|
| embankment_classification | 盛土区分 | 文字列型 | 谷埋め型 | 区分の文字列（他に「腹付け型」等が想定されるが値セットは原典参照・未確認） |
| prefecture_code | 都道府県コード | 文字列型 | 28 | |
| prefecture_name | 都道府県名 | 文字列型 | 兵庫県 | |
| city_code | 市区町村コード | 文字列型 | 28215 | 5桁。XKT021/022 の `group_code` に相当（キー名が異なる） |
| city_name | 市区町村名 | 文字列型 | 三木市 | |
| embankment_number | 盛土番号 | 文字列型 | 三木08-03 | |

- ※ 出力例の `properties` には上記に加え、IF表に無い内部フィールド **`_id`・`_index`（例: `bs023_developed_land_202406281750`）が含まれる**（防災系共通。要確認＝未文書・依存しない方が安全）。並び順は IF 表順と不一致（キー名参照が前提）。

## 4. 使用例
リクエスト（Windows コマンドプロンプト。GeoJSON取得）:
```
curl -H "Ocp-Apim-Subscription-Key:{発行されたAPIキー}" "https://www.reinfolib.mlit.go.jp/ex-api/external/XKT020?response_format=geojson&z=14&x=14340&y=6496" > XKT020.geojson
```
レスポンス例（GeoJSON。座標列が膨大なため `coordinates` は中略。Polygon と MultiPolygon の両 Feature を示す）:
