XIT001. 不動産価格（取引価格・成約価格）情報取得API
下記パラメータを指定することで、不動産価格（取引価格・成約価格）情報を取得できます。
https://www.reinfolib.mlit.go.jp/ex-api/external/XIT001?＜パラメータ＞

＜パラメータ＞
パラメータ	内容	備考	必須
priceClassification	価格情報区分コード	形式はNN（数字2桁）
01 … 不動産取引価格情報のみ
02 … 成約価格情報のみ
未指定 … 不動産取引価格情報と成約価格情報の両方	
year	取引時期（年）	形式はYYYY（数字4桁）
YYYY … 西暦
※取引価格は2005（2005年は第3四半期（7~9月）と第4四半期（10~12月）のみ）より指定可能
※成約価格は2021より指定可能	○
quarter	取引時期（四半期）	形式はN（数字1桁）
N … 1～4（1:1月～3月、2:4月～6月、3:7月～9月、4:10月～12月）	
area	都道府県コード	形式はNN（数字2桁）
※複数指定する場合は、「prefectureCode=09,10」のようにカンマ区切りで指定してください。

都道府県コードの詳細は、「XIT002.都道府県内市区町村一覧取得API」の＜参考＞を参照。	※１
city	市区町村コード	形式はNNNNN（数字5桁）
NNNNN … 全国地方公共団体コードの上5桁	※１
station	駅コード	形式はNNNNNN（数字6桁）
NNNNNN … 駅コード
国土数値情報の駅データ（鉄道データの下位クラス）のグループコード（N02_005g）を指定します。

https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N02-v3_1.htmlを参照。	※１
language	出力結果の言語	ja…日本語
en…英語
未指定…日本語	
※１：area, city, stationのうち、少なくとも一つは値を指定する必要があります。
＜出力＞
※出力データはgzipでエンコードされているため、クライアントでデコードを必要とする場合があります。

Municipality	市区町村名	文字列型	中央区	※２

PricePerUnit	坪単価	文字列型		
FloorPlan	間取り	文字列型		※２

LandShape	土地の形状	文字列型	不整形	※２
Frontage	間口	文字列型	6	
TotalFloorArea	延床面積（平方メートル）	文字列型	240

※２: languageの設定に合わせた言語で出力します。データ例には日本語の出力例を掲載しています。

＜使用例＞
Windowsのコマンドプロンプトで、JSONを取得する場合のコマンド例（gzipのデコードオプションを付与しています。）

コピー
curl -H "Ocp-Apim-Subscription-Key:{発行されたAPIキー}" --compressed "https://www.reinfolib.mlit.go.jp/ex-api/external/XIT001?year=2015&quarter=2&city=13102&priceClassification=01" > XIT001.json
