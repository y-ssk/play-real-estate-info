# XIT001. 不動産価格（取引価格・成約価格）情報取得API

> MLIT 不動産情報ライブラリ API の IF 定義（公式マニュアルからの生コピペを構造化したもの）。
> 転記のみ。原文で確認できない項目は「未確認」と明記。実装着手前に本書を最終確認する。

## 1. 概要
- 振り分け: ETL（`docs/02_architecture.md` 第3節。XIT001=JSON→ETL）
- 形式: JSON
- 取得粒度: 取引レコード（`area` / `city` / `station` で絞り込み）
- エンドポイント: `https://www.reinfolib.mlit.go.jp/ex-api/external/XIT001?<パラメータ>`
- 認証: ヘッダ `Ocp-Apim-Subscription-Key: <APIキー>`（キーは環境変数 `MLIT_API_KEY`。**AIは値に触れない**）
- エンコード: gzip（`curl` は `--compressed`。クライアントでのデコードが必要な場合あり）

## 2. リクエストパラメータ
| パラメータ | 内容 | 形式 | 必須 | 備考 |
|---|---|---|---|---|
| priceClassification | 価格情報区分コード | NN（数字2桁） | 任意 | 01=不動産取引価格情報のみ / 02=成約価格情報のみ / 未指定=両方 |
| year | 取引時期（年） | YYYY（数字4桁） | ○ | 取引価格は2005〜（2005は第3四半期(7-9月)と第4四半期(10-12月)のみ）、成約価格は2021〜 |
| quarter | 取引時期（四半期） | N（数字1桁） | 任意 | 1〜4（1:1-3月, 2:4-6月, 3:7-9月, 4:10-12月） |
| area | 都道府県コード | NN（数字2桁） | ※1 | 複数指定はカンマ区切り（原文例は「prefectureCode=09,10」＝パラメータ名の表記ゆれ、要確認）。コード詳細は XIT002 ＜参考＞ |
| city | 市区町村コード | NNNNN（数字5桁） | ※1 | 全国地方公共団体コードの上5桁 |
| station | 駅コード | NNNNNN（数字6桁） | ※1 | 国土数値情報 駅データの `N02_005g` グループコード（上記参照URL） |
| language | 出力結果の言語 | ja / en | 任意 | 未指定=日本語 |

制約（※注記）:
- ※1: `area`, `city`, `station` のうち、少なくとも一つは値を指定する必要がある。

## 4. 使用例
リクエスト（Windows コマンドプロンプト。gzip デコードオプション付与）:
```
curl -H "Ocp-Apim-Subscription-Key:{発行されたAPIキー}" --compressed "https://www.reinfolib.mlit.go.jp/ex-api/external/XIT001?year=2015&quarter=2&city=13102&priceClassification=01" > XIT001.json
```
