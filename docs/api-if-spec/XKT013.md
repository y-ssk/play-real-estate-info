# XKT013. 国土数値情報（将来推計人口250mメッシュ）API

> MLIT 不動産情報ライブラリ API の IF 定義（公式マニュアルからの生コピペを構造化したもの）。
> 転記のみ。原文で確認できない項目は「未確認」と明記。実装着手前に本書を最終確認する。

## 1. 概要
- 振り分け: タイル配信（`docs/02_architecture.md` 第3節。XKT 系=GISデータ→タイル配信）。**ただし「街の将来」の主軸**＝指標化（ETL/両用）の価値が高い
- 形式: GISデータ（GeoJSON / バイナリベクトルタイル pbf）。XYZ タイル方式で取得
- 取得粒度: **250mメッシュ**（`MESH_ID`＝分割地域メッシュコード）。タイル（z/x/y）。属性フィルタ無し
- 内容: 2020年（基準）〜2070年の**将来推計人口**を、年齢5歳階級・集約区分・比率でメッシュ別に保持。`docs/02`§8 のメッシュ粒度（v1）と直結
- エンドポイント: `https://www.reinfolib.mlit.go.jp/ex-api/external/XKT013?<パラメータ>`
- 認証: ヘッダ `Ocp-Apim-Subscription-Key: <APIキー>`（キーは環境変数 `MLIT_API_KEY`。**AIは値に触れない**）
- エンコード: 原文に gzip/`--compressed` の記載なし（使用例にもオプションなし）。要確認
- 座標系: 出力例の CRS は `urn:ogc:def:crs:EPSG::6668`（JGD2011 地理座標系）

## 3. レスポンス（出力）
包み構造: GeoJSON `FeatureCollection`（`name` は `estimated_future_population`、`crs` は EPSG:6668）。`geometry.type` は `Polygon`（250mメッシュの矩形）。
- **重要: IF表のタグ名は `20XX` を含むテンプレート表記**。実際の JSON は推計**年次ごとに展開**され、`PT00_2025`・`RTC_2045` のように `20XX` が各年に置換される。
- 出力例に存在する年次: **`2020`, `2025`, `2030`, `2035`, `2040`, `2045`, `2050`, `2055`, `2060`, `2065`, `2070`**（5年刻み・計11年次。2020=基準、以降が推計）。正確な提供年次の確定は原典参照（要確認）。
- 人口値は **実数型**（メッシュ按分のため小数。例 `381.1961975097656`）。比率（RT系）も実数。

### キー（メッシュ識別）
| タグ名 | 内容 | データ型 | データ例 | 備考 |
|---|---|---|---|---|
| MESH_ID | 分割地域メッシュコード | 文字列型 | 6240552941 | 250mメッシュ。空間キー候補 |
| SHICODE | 行政区域コード | 文字列型 | 01202 | 5桁（市区町村）。市区町村集計のキー |

### 年次展開フィールド（各タグの `20XX` は上記の各年次に置換。データ例は原文の代表値）
| タグ（テンプレート） | 内容 | データ型 | データ例 | 備考 |
|---|---|---|---|---|
| PTN_20XX | 男女計総数人口（**秘匿なし**） | 実数型 | 381.1962 | 秘匿処理前の生値 |
| HITOKU20XX | 秘匿記号 | 文字列型 | （空） | 統計秘匿フラグ。空=秘匿なし（要確認）。※他と異なり `_` 無しの `HITOKU2025` 形式 |
| GASSAN20XX | 合算先メッシュ | 整数型 | （空） | 秘匿時の合算先メッシュ。※`GASSAN2025` 形式 |
| PT00_20XX | 男女計総数人口 | 実数型 | 381.1962 | PTN との差＝秘匿処理の有無（要確認） |
| PT01_20XX 〜 PT20_20XX | 男女計の5歳階級別人口 | 実数型 | 8.1604 等 | PT01=0〜4歳 / PT02=5〜9歳 / … / PT19=90〜94歳 / PT20=95歳以上（5歳刻み、PT20のみ上限開放） |
| PTA_20XX | 男女計 0〜14歳人口（年少） | 実数型 | 41.0135 | 集約区分 |
| PTB_20XX | 男女計 15〜64歳人口（生産年齢） | 実数型 | 205.0405 | 集約区分 |
| PTC_20XX | 男女計 65歳以上人口（老年） | 実数型 | 135.1422 | 集約区分 |
| PTD_20XX | 男女計 75歳以上人口 | 実数型 | 76.2427 | 集約区分 |
| PTE_20XX | 男女計 80歳以上人口 | 実数型 | 37.5101 | 集約区分 |
| RTA_20XX | 0〜14歳人口比率 | 実数型 | 0.1076 | 比率（0〜1） |
| RTB_20XX | 15〜64歳人口比率 | 実数型 | 0.5379 | 比率 |
| RTC_20XX | 65歳以上人口比率（高齢化率） | 実数型 | 0.3545 | **高齢化率＝街の素性指標に直結** |
| RTD_20XX | 75歳以上人口比率 | 実数型 | 0.2 | 比率 |
| RTE_20XX | 80歳以上人口比率 | 実数型 | 0.0984 | 比率 |

- ※ 各年次（11年）× 上記系統（PTN/HITOKU/GASSAN/PT00〜20/PTA〜E/RTA〜E ≒ 34）で**1メッシュあたり数百項目**になる。
- ※ 出力例の `properties` には IF表に無い内部フィールド **`_id`・`_index`（例: `bs012_estimated_future_population_202502071921`）が含まれる**。要確認＝未文書・依存しない方が安全。
- ※ プロパティ並び順は不定（キー名参照が前提）。

## 5. MachiLens 取り込み観点（実装・レビューの足場）
> 着手段階で AI が記入する欄。空欄は「未検討」。**「街の将来」の主軸＝差別化の核（面・将来）に直結**。
- 振り分け方針: タイル＋ETL/両用が有力。**RTC（高齢化率）・PTB（生産年齢）・総数の推移**は市区町村/メッシュの「将来」指標として強力。MVP（市区町村粒度）ではメッシュ→市区町村集計、v1 でメッシュ表示（`docs/02`§8）。`docs/99` 保留「防災レイヤーの扱い（=指標化方針）」と同様の設計判断（P2）。
- 取り込み対象フィールド / PostGIS マッピング: 未検討（`MESH_ID`＝メッシュキー、`SHICODE`＝市区町村結合キー。全項目取り込みは過大＝**必要年次・系統に絞る**。例: 総数 PTN/PT00、RTC 高齢化率、PTB 生産年齢の数年次）
- 一意キー（冪等性の判定キー）: 未検討（候補: `MESH_ID`。年次は列展開で1メッシュ1行 or 縦持ち（メッシュ×年）かは設計判断）
- 値域・整合チェック（層1）: 未検討（人口は非負実数、RT系は0〜1、PT01〜20の合計≒PT00、PTA+PTB+PTC≒総数、`SHICODE`5桁、秘匿（HITOKU）時の値の扱い）
- 欠損の扱い（"データなし" の判定と UI 表示への接続）: 未検討（**統計秘匿＝HITOKU/GASSAN**。小人口メッシュは秘匿/合算され値が欠ける＝「データなし」と区別して扱う）
- 出典の保持（MLIT 出典の紐づけ＝法的要件）: 未検討（国土数値情報・将来推計人口）
- レート制御メモ（連続実行を避ける）: 未検討（メッシュ全面＋多項目で1レスポンスが重い。z選択で件数調整）
- 未確認・要確認事項:
  - 転記元の公式ドキュメント URL／「原典データ項目」詳細ページ URL
  - gzip エンコードの要否（原文に記載なし）
  - 提供年次の正確なセット（例では2020〜2070の5年刻み。原典で確定）
  - `PTN`（秘匿なし）と `PT00`（総数）の差＝秘匿処理の仕様、`HITOKU`/`GASSAN` の値と意味
  - 男女別の有無（本IFは「男女計」のみ。男女別系統が別途あるか）
  - 未文書フィールド `_id` / `_index` の位置づけ
