# XKT010. 国土数値情報（医療機関）API

> MLIT 不動産情報ライブラリ API の IF 定義（公式マニュアルからの生コピペを構造化したもの）。

## 1. 概要
- 振り分け: タイル配信（`docs/02_architecture.md` 第3節。XKT 系=GISデータ→タイル配信。生活環境・周辺施設レイヤー）
- 形式: GISデータ（GeoJSON / バイナリベクトルタイル pbf）。XYZ タイル方式で取得
- 取得粒度: **施設の点（Point）**。タイル（z/x/y 指定。ズーム 13〜15）。属性フィルタ無し
- 内容: 病院・診療所等の医療機関。診療科目・病床数・救急/災害拠点の別を持つ
- エンドポイント: `https://www.reinfolib.mlit.go.jp/ex-api/external/XKT010?<パラメータ>`
- 認証: ヘッダ `Ocp-Apim-Subscription-Key: <APIキー>`（キーは環境変数 `MLIT_API_KEY`。**AIは値に触れない**）
- エンコード: 原文に gzip/`--compressed` の記載なし（使用例にもオプションなし）。要確認
- 座標系: 出力例の CRS は `urn:ogc:def:crs:EPSG::6668`（JGD2011 地理座標系）

## 2. リクエストパラメータ
| パラメータ | 内容 | 形式 | 必須 | 備考 |
|---|---|---|---|---|
| response_format | 応答形式 | geojson / pbf | ○ | geojson…GeoJSON応答 / pbf…バイナリベクトルタイル応答 |
| z | ズームレベル（縮尺） | 整数 | ○ | 13（大字）〜15（詳細）で指定可能。値が大きいほど高ズーム |
| x | タイル座標のX値 | 整数 | ○ | XYZ方式のX値 |
| y | タイル座標のY値 | 整数 | ○ | XYZ方式のY値 |

制約（※注記）:
- XYZ方式の詳細は GSI の確認ツール参照。z は 13〜15。属性フィルタは無し。

## 3. レスポンス（出力）
包み構造: GeoJSON `FeatureCollection`（`name` は `medical_institution`。`crs` は EPSG:6668）。`geometry.type` は `Point`。タグ命名は `P04_###` コード系＋末尾に snake_case の `medical_subject_ja`。型は整数/文字列が混在。

各 Feature の `properties`（タグ）:

| タグ名 | 内容 | データ型 | データ例 | 備考 |
|---|---|---|---|---|
| P04_001 | 医療機関分類 | 整数型 | 2 | コード値（観測: 2=診療所。病院等の他値は原典参照・要確認）。対応名称は `P04_001_name_ja` |
| P04_001_name_ja | 医療機関分類名 | 文字列型 | 診療所 | `P04_001` の名称 |
| P04_002_ja | 施設名称 | 文字列型 | ラインインターナショナルクリニック | |
| P04_003_ja | 所在地 | 文字列型 | 世田谷区上馬五丁目９番１８号 | 全角番地 |
| P04_004 | 診療科目１ | 文字列型 | 内科 | 例によっては複数科目が全角スペース区切りで1値に入る |
| P04_005 | 診療科目２ | 文字列型 | （空） | |
| P04_006 | 診療科目３ | 文字列型 | （空） | |
| P04_007 | 開設者分類 | 整数型 | 9 | コード値（`9` は不明/該当なしの番兵の可能性＝要確認） |
| P04_008 | 病床数 | 整数型 | 0 | 診療所は 0 の例。**実数の病床数**（層1で非負チェック） |
| P04_009 | 救急告示病院 | 整数型 | 9 | コード値（`9`＝該当なし/不明の可能性。要確認） |
| P04_010 | 災害拠点病院 | 整数型 | 9 | コード値（同上。防災との接続に有用だが凡例要確認） |
| medical_subject_ja | 診療科目 | 文字列型 | 内科 | 診療科目をまとめた文字列（`P04_004`〜`006` の集約的表現。命名のみ snake_case） |

- ※ 出力例の `properties` には IF表に無い内部フィールド **`_id`・`_index`（例: `bs007_medical_institution_202403181840`）が含まれる**（要確認＝未文書・依存しない方が安全）。並び順は IF 表順と不一致（キー名参照が前提）。

## 4. 使用例
リクエスト（Windows コマンドプロンプト。GeoJSON取得）:
```
curl -H "Ocp-Apim-Subscription-Key:{発行されたAPIキー}" "https://www.reinfolib.mlit.go.jp/ex-api/external/XKT010?response_format=geojson&z=15&x=29095&y=12908" > XKT010.geojson
```
レスポンス例（GeoJSON。点データ。Feature 1件分を原文どおり。実際は多数）:
```
{
  "type": "FeatureCollection",
  "name": "medical_institution",
  "crs": { "type": "name", "properties": { "name": "urn:ogc:def:crs:EPSG::6668" } },
  "features": [
    {
      "type": "Feature",

        "P04_002_ja": "ラインインターナショナルクリニック",
```
