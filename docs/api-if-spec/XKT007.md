# XKT007. 国土数値情報（保育園・幼稚園等）API

> MLIT 不動産情報ライブラリ API の IF 定義（公式マニュアルからの生コピペを構造化したもの）。
> 転記のみ。原文で確認できない項目は「未確認」と明記。実装着手前に本書を最終確認する。

## 1. 概要
- 振り分け: タイル配信（`docs/02_architecture.md` 第3節。XKT 系=GISデータ→タイル配信。生活環境・周辺施設レイヤー）
- 形式: GISデータ（GeoJSON / バイナリベクトルタイル pbf）。XYZ タイル方式で取得
- 取得粒度: **施設の点（Point）**。タイル（z/x/y 指定。ズーム 13〜15）。属性フィルタ無し
- 内容: 保育園・幼稚園・こども園。子育て世帯の住み替え判断に直結
- **重要: 施設種別で2系統のフィールドを持つ**（下記）。タグ命名は **camelCase**（他の多くの XKT＝`A##_###`/snake_case と異なる）
- エンドポイント: `https://www.reinfolib.mlit.go.jp/ex-api/external/XKT007?<パラメータ>`
- 認証: ヘッダ `Ocp-Apim-Subscription-Key: <APIキー>`（キーは環境変数 `MLIT_API_KEY`。**AIは値に触れない**）
- エンコード: 原文に gzip/`--compressed` の記載なし（使用例にもオプションなし）。要確認
- 座標系: 出力例の CRS は `urn:ogc:def:crs:EPSG::6668`（JGD2011 地理座標系）

### URL（転記元・参照先）
- 公式ドキュメント（転記元URL）: **未確認**（生コピペにページ URL の記載なし。要確認）
- 仕様内で参照される外部URL:
  - `https://maps.gsi.go.jp/development/tileCoordCheck.html` … XYZ方式（タイル座標 z/x/y）の確認ツール
  - 「＜原典データ項目について＞」… 幼稚園/こども園 と 保育園 で**別々の原典ページ**（**出力項目のコード定義は各リンク参照**と原文明記。リンク先 URL は生コピペに未記載。要確認）

## 2. リクエストパラメータ
| パラメータ | 内容 | 形式 | 必須 | 備考 |
|---|---|---|---|---|
| response_format | 応答形式 | geojson / pbf | ○ | geojson…GeoJSON応答 / pbf…バイナリベクトルタイル応答 |
| z | ズームレベル（縮尺） | 整数 | ○ | 13（大字）〜15（詳細）で指定可能。値が大きいほど高ズーム |
| x | タイル座標のX値 | 整数 | ○ | XYZ方式のX値 |
| y | タイル座標のY値 | 整数 | ○ | XYZ方式のY値 |

制約（※注記）:
- XYZ方式の詳細は GSI の確認ツール参照。z は 13〜15。属性フィルタは無し（`administrativeAreaCode` は**出力項目**であり入力パラメータではない）。

## 3. レスポンス（出力）
包み構造: GeoJSON `FeatureCollection`（`name` は `preschool`。`crs` は EPSG:6668）。`geometry.type` は `Point`。
- ⚠ **施設種別で2系統のフィールドを持つ**。原文は (i)幼稚園/こども園 と (ii)保育園 で別表。出力例では**両系統のキーが1オブジェクトに同居**し、非該当系統は空文字（例: 幼稚園レコードは `welfareFacility*` が `""`）。
- 共通フィールド: `administrativeAreaCode`・`preSchoolName_ja`・`location_ja`・`administratorCode`。

### (i) 幼稚園・こども園系フィールド
| タグ名 | 内容 | データ型 | データ例 | 備考 |
|---|---|---|---|---|
| administrativeAreaCode | 行政区域コード | 文字列型 | 13110 | 5桁（出力項目。入力paramではない） |
| preSchoolName_ja | 名称 | 文字列型 | 目黒区立げっこうはらこども園 | |
| schoolCode | 学校コード | 文字列型 | A113211000023 | 先頭 `A`（幼稚園系。XKT006 は B 小学校/C 中学校） |
| schoolClassCode | 学校分類コード | 整数型 | 16011 | コード値（16011=幼稚園。XKT006 の体系と連続） |
| schoolClassCode_name_ja | 学校分類名 | 文字列型 | 幼稚園 | `schoolClassCode` の名称 |
| location_ja | 所在地 | 文字列型 | 東京都目黒区目黒本町4-15-3 | |
| administratorCode | 管理者コード | 整数型 | 3 | コード値（定義は原典参照・要確認） |
| closeSchoolCode | 休校コード | 整数型 | 0 | コード値（0の意味＝開園/休園は原典参照・要確認） |

### (ii) 保育園系フィールド
| タグ名 | 内容 | データ型 | データ例 | 備考 |
|---|---|---|---|---|
| administrativeAreaCode | 行政区域コード | 文字列型 | 13110 | 5桁 |
| preSchoolName_ja | 名称 | 文字列型 | 目黒かえで保育園 | |
| welfareFacilityClassCode | 福祉施設大分類コード | 文字列型 | 05 | 3階層コードの大分類 |
| welfareFacilityMiddleClassCode | 福祉施設中分類コード | 文字列型 | 0504 | 中分類 |
| welfareFacilityMinorClassCode | 福祉施設小分類コード | 文字列型 | 050401 | 小分類（XKT011 福祉施設と同体系の可能性） |
| location_ja | 所在地 | 文字列型 | 中央町2-32-22 | |
| administratorCode | 管理者コード | 整数型 | 5 | コード値 |

- ※ 出力例の `properties` には IF表に無い内部フィールド **`_id`・`_index`（例: `bs006_preschool_202406281926`）が含まれる**（要確認＝未文書・依存しない方が安全）。並び順は IF 表順と不一致（キー名参照が前提）。

## 4. 使用例
リクエスト（Windows コマンドプロンプト。GeoJSON取得）:
```
curl -H "Ocp-Apim-Subscription-Key:{発行されたAPIキー}" "https://www.reinfolib.mlit.go.jp/ex-api/external/XKT007?response_format=geojson&z=14&x=14549&y=6454" > XKT007.geojson
```
レスポンス例（GeoJSON。点データ。幼稚園レコード1件分を原文どおり。保育園系キーは空文字で同居）:
```
{
  "type": "FeatureCollection",
  "name": "preschool",
  "crs": { "type": "name", "properties": { "name": "urn:ogc:def:crs:EPSG::6668" } },
  "features": [
    {
      "type": "Feature",
      "geometry": { "type": "Point", "coordinates": [139.6945309638977, 35.62252379134752] },
      "properties": {
        "_id": "ATtiXpABrlAdLUL0hJcw",
        "_index": "bs006_preschool_202406281926",
        "administrativeAreaCode": "13110",
        "preSchoolName_ja": "目黒区立げっこうはらこども園",
        "schoolCode": "A113211000023",
        "schoolClassCode": 16011,
        "schoolClassCode_name_ja": "幼稚園",
        "location_ja": "東京都目黒区目黒本町4-15-3",
        "administratorCode": 3,
        "closeSchoolCode": 0,
        "welfareFacilityClassCode": "", "welfareFacilityMiddleClassCode": "", "welfareFacilityMinorClassCode": ""
      }
    }
    /* features は多数。保育園レコードは welfareFacility* が埋まり school* 系が空 */
  ]
}
```
