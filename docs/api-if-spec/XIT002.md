# XIT002. 都道府県内市区町村一覧取得API

> MLIT 不動産情報ライブラリ API の IF 定義（公式マニュアルからの生コピペを構造化したもの）。
> 転記のみ。原文で確認できない項目は「未確認」と明記。実装着手前に本書を最終確認する。

## 1. 概要
- 振り分け: ETL（`docs/02_architecture.md` 第3節。XIT 系=JSON→ETL。本APIはマスタ／コード参照用の一覧取得）
- 形式: JSON
- 取得粒度: 市区町村（指定した都道府県内の一覧）
- エンドポイント: `https://www.reinfolib.mlit.go.jp/ex-api/external/XIT002?<パラメータ>`
- 認証: ヘッダ `Ocp-Apim-Subscription-Key: <APIキー>`（キーは環境変数 `MLIT_API_KEY`。**AIは値に触れない**）
- エンコード: gzip（`curl` は `--compressed`。クライアントでのデコードが必要な場合あり）

### URL（転記元・参照先）
- 公式ドキュメント（転記元URL）: **未確認**（生コピペにページ URL の記載なし。要確認）
- 仕様内で参照される外部URL: なし（本文に外部URLの記載なし）
- 本書が他APIから参照される: XIT001 ほかの `area`（都道府県コード）の詳細として、本書末尾の「＜参考＞都道府県コード一覧」を参照

## 2. リクエストパラメータ
| パラメータ | 内容 | 形式 | 必須 | 備考 |
|---|---|---|---|---|
| area | 都道府県コード | NN（数字2桁） | ○ | NN…都道府県コード（末尾の＜参考＞一覧参照） |
| language | 出力結果の言語 | ja / en | 任意 | ja…日本語 / en…英語 / 未指定=日本語 |

制約（※注記）:
- 原文に追加の制約注記なし。

## 3. レスポンス（出力）
包み構造: `{ "status": "OK", "data": [ { ... }, ... ] }`（gzip でエンコードされて出力）

| タグ名 | 内容 | データ型 | データ例 | 備考 |
|---|---|---|---|---|
| id | 市区町村コード | 文字列型 | 13101 | |
| name | 市区町村名（日本語） | 文字列型 | 千代田区 | ※1 |
| name | 市区町村名（英語） | 文字列型 | Chiyoda Ward | ※1 |

- ※1: 原文では日本語名・英語名がいずれも同じタグ名 `name` で記載されている。`language` の指定（ja/en）に応じて出力言語が切り替わる想定。1レスポンス内に和英両方が並ぶのか、言語ごとに `name` の中身が変わるのかは原文から判別できない（要確認）。出力例（下記）は `name` が日本語1つのみ。

## 4. 使用例
リクエスト（Windows コマンドプロンプト。gzip デコードオプション付与）:
```
curl -H "Ocp-Apim-Subscription-Key:{発行されたAPIキー}" --compressed "https://www.reinfolib.mlit.go.jp/ex-api/external/XIT002?area=13" > XIT002.json
```
