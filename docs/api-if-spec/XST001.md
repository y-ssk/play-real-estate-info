## 1. 概要
- 提供元: 国土調査（土地履歴調査）
- 振り分け: タイル配信（`docs/02_architecture.md` 第3節。XST 系=GISデータ→タイル配信。防災コアの一枚＝過去の災害実績）
- 形式: GISデータ（GeoJSON / バイナリベクトルタイル pbf）。XYZ タイル方式で取得
- 取得粒度: タイル（z/x/y 指定。ズーム **9（都道府県）〜15（詳細）**＝これまでで最広）。`disastertype_code` で災害分類フィルタ可
- 注記（原文）: 一部のサイズが大きいポリゴンや複雑なポリゴンは分割して提供しているため、原典データと形状が一致しない場合がある
- エンドポイント: `https://www.reinfolib.mlit.go.jp/ex-api/external/XST001?<パラメータ>`
- 認証: ヘッダ `Ocp-Apim-Subscription-Key: <APIキー>`（キーは環境変数 `MLIT_API_KEY`。**AIは値に触れない**）
- エンコード: 原文に gzip/`--compressed` の記載なし（使用例にもオプションなし）。要確認
- 座標系: 出力例の CRS は `urn:ogc:def:crs:EPSG::6668`（JGD2011 地理座標系。防災系の多くと同じ）

## 2. リクエストパラメータ
| パラメータ | 内容 | 形式 | 必須 | 備考 |
|---|---|---|---|---|
| response_format | 応答形式 | geojson / pbf | ○ | geojson…GeoJSON応答 / pbf…バイナリベクトルタイル応答 |
| z | ズームレベル（縮尺） | 整数 | ○ | **9（都道府県）〜15（詳細）** で指定可能。値が大きいほど高ズーム（カバー領域は狭い） |
| x | タイル座標のX値 | 整数 | ○ | XYZ方式のX値 |
| y | タイル座標のY値 | 整数 | ○ | XYZ方式のY値 |
| disastertype_code | 災害分類コード | NN（数字2桁） | （任意。未指定の場合はすべて） | 複数指定はカンマ区切り（例: `disastertype_code=11,22,37`）。コード値は下記＝**原文にインライン記載あり** |

- XYZ方式の詳細は GSI の確認ツール（上記参照URL）を参照。
- z は 9〜15 で指定可能。`disastertype_code` 未指定なら全分類。

## 3. レスポンス（出力）
包み構造: GeoJSON `FeatureCollection`（`response_format=geojson` の場合。例の `name` は `disaster_history`）。`response_format=pbf` ではバイナリベクトルタイル。
- タグ命名は説明的 snake_case。`disastertype_code` はリクエスト（NN）／レスポンス（文字列）の双方に出る。

各 Feature の `properties`（タグ）:

| タグ名 | 内容 | データ型 | データ例 | 備考 |
|---|---|---|---|---|
| disastertype_code | 災害分類コード | 文字列型 | 11 | 上記コード表参照（凡例は本書 §2 にインライン） |
| disaster_name_ja | 分類の呼称（災害種別等） | 文字列型 | 浸水域 | `disastertype_code` の呼称（凡例インライン）。`_ja` サフィックス |
| disaster_date | 西暦年月日 | 文字列型 | 19740707 | **8桁 `YYYYMMDD`**。年代/年以降/年月以降が不明なデータは不明箇所を「0」とし8桁出力（例: `00000000`, `19810000`, `19820700`）＝また別の日付表現 |
| disaster_source | 資料名（発行者） | 文字列型 | 太田川水系河川整備計画（静岡県） | 出典資料名 |

- ※ 出力例の `properties` には上記に加え、IF表に無い内部フィールド **`_id`・`_index`（例: `bs036_disaster_history_202510291624`）が含まれる**（防災系共通。要確認＝未文書・依存しない方が安全）。並び順は IF 表順と不一致（キー名参照が前提）。

## 4. 使用例
リクエスト（Windows コマンドプロンプト。GeoJSON取得）:
```
curl -H "Ocp-Apim-Subscription-Key:{発行されたAPIキー}" "https://www.reinfolib.mlit.go.jp/ex-api/external/XST001?response_format=geojson&z=14&x=14467&y=6503" > XST001.geojson
```
レスポンス例（GeoJSON。座標列が膨大なため `coordinates` は中略。構造・CRS・properties は原文どおり、Feature 1件分を示す）:
```
{
  "type": "FeatureCollection",
  "name": "disaster_history",
  "crs": { "type": "name", "properties": { "name": "urn:ogc:def:crs:EPSG::6668" } },
  "features": [
    {
      "type": "Feature",
      "geometry": {
        "type": "Polygon",
        "coordinates": [ [ [137.88979053497314, 34.75968816036821], [137.89843797683716, 34.75968816036821], ... ] ]
      },
      "properties": {
        "_id": "AdbcLpoB2Vp85HbxjZwu",
        "_index": "bs036_disaster_history_202510291624",
        "disaster_date": "19740707",
        "disaster_name_ja": "浸水域",
        "disaster_source": "太田川水系河川整備計画（静岡県）",
```
