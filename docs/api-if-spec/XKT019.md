# XKT019. 国土数値情報（自然公園地域）API

> MLIT 不動産情報ライブラリ API の IF 定義（公式マニュアルからの生コピペを構造化したもの）。
> 転記のみ。原文で確認できない項目は「未確認」と明記。実装着手前に本書を最終確認する。

## 1. 概要
- 振り分け: タイル配信（`docs/02_architecture.md` 第3節。XKT 系=GISデータ→タイル配信。生活環境・周辺施設レイヤー）
- 形式: GISデータ（GeoJSON / バイナリベクトルタイル pbf）。XYZ タイル方式で取得
- 取得粒度: **自然公園地域の区域ポリゴン**。タイル（z/x/y 指定。ズーム 9〜15）＋ `prefectureCode` / `districtCode`（振興局）で絞り込み
- 内容: 国立/国定/都道府県立自然公園等の地域。緑・自然環境の指標
- エンドポイント: `https://www.reinfolib.mlit.go.jp/ex-api/external/XKT019?<パラメータ>`
- 認証: ヘッダ `Ocp-Apim-Subscription-Key: <APIキー>`（キーは環境変数 `MLIT_API_KEY`。**AIは値に触れない**）
- エンコード: 原文に gzip/`--compressed` の記載なし（使用例にもオプションなし）。要確認
- 座標系: 出力例の CRS は **`urn:ogc:def:crs:EPSG::4612`（JGD2000）**（XKT017 と同じ。EPSG:6668 系と不統一）

## 2. リクエストパラメータ
| パラメータ | 内容 | 形式 | 必須 | 備考 |
|---|---|---|---|---|
| response_format | 応答形式 | geojson / pbf | ○ | geojson…GeoJSON応答 / pbf…バイナリベクトルタイル応答 |
| z | ズームレベル（縮尺） | 整数 | ○ | **9（都道府県）〜15（詳細）** で指定可能。値が大きいほど高ズーム |
| x | タイル座標のX値 | 整数 | ○ | XYZ方式のX値 |
| y | タイル座標のY値 | 整数 | ○ | XYZ方式のY値 |
| prefectureCode | 都道府県コード | N または NN（1〜47） | （任意。原文の必須欄は空） | **先頭0を除いた値**で指定（例: 北海道=1, 沖縄=47）。複数指定はカンマ区切り（`prefectureCode=9,11`）。PrefCd.html 参照。※他APIの NN 2桁固定と異なる |
| districtCode | 地区コード（振興局区域） | N または NN | （任意） | 振興局区域を一意に識別。先頭0除去。複数指定はカンマ区切り。SubprefectureNameCd.html 参照 |

制約（※注記）:
- XYZ方式の詳細は GSI の確認ツール参照。z は 9〜15。
- `prefectureCode`/`districtCode` の必須/任意は原文の必須欄が空のため**任意と判断**（要確認）。コードは**先頭0を除いて**指定する点に注意。

## 3. レスポンス（出力）
包み構造: GeoJSON `FeatureCollection`（`name` は `natural_park_area`。`crs` は EPSG:4612）。`geometry.type` は `Polygon`。
- ⚠ **タグ命名が ESRI シェープファイル由来の全大文字**（`OBJECTID`・`PREFEC_CD`・`Shape_Leng`・`Shape_Area` 等）＝他の XKT（`A##_###`/`P##_###`/snake_case/camelCase）と**さらに異なる第5の命名系**。

各 Feature の `properties`（タグ）:

| タグ名 | 内容 | データ型 | データ例 | 備考 |
|---|---|---|---|---|
| OBJECTID | シェープID | 整数型 | 49165 | ESRI 由来の一意ID候補 |
| PREFEC_CD | 都道府県コード | 文字列型 | 15 | 出力は2桁文字列（入力paramは先頭0除去だが出力は2桁の模様。要確認） |
| AREA_CD | 地区コード | 文字列型 | 0 | 振興局区域コード |
| CTV_NAME | 市町村名 | 文字列型 | （空）/能生町 | 空の例あり |
| FIS_YEAR | 年度 | 文字列型 | 2002 | データ年度 |
| THEMA_NO | 主題番号 | 整数型 | 1 | コード値（要確認） |
| LAYER_NO | レイヤ番号 | 整数型 | 11 | コード値（公園種別を示す可能性。観測 11/12。要確認） |
| AREA_SIZE | ポリゴン面積(ha) | 実数型 | 58143.5 | ha 単位の面積 |
| IOSIDE_DIV | 内外区分 | 整数型 | 1 | コード値（観測 1/0。公園区域の内/外等。要確認） |
| REMARK_STR | 備考 | 文字列型 | （空） | |
| Shape_Leng | シェープの長さ | 実数型 | 0.1893521398305893 | **度単位**（ESRI 計算値。CRS が地理座標のため度）。実距離ではない |
| Shape_Area | シェープの面積 | 実数型 | 0.0005896130460314453 | **度単位**（同上。面積指標には `AREA_SIZE`(ha) を使う） |
| OBJ_NAME_ja | シェープ名 | 文字列型 | 久比岐自然公園地域 | 公園名（空の例あり） |

- ※ 出力例の `properties` には IF表に無い内部フィールド **`_id`・`_index`（例: `bs017_natural_park_area_202403211842`）が含まれる**（要確認＝未文書・依存しない方が安全）。並び順は IF 表順と不一致（キー名参照が前提）。

## 4. 使用例
リクエスト（Windows コマンドプロンプト。GeoJSON取得）:
```
curl -H "Ocp-Apim-Subscription-Key:{発行されたAPIキー}" "https://www.reinfolib.mlit.go.jp/ex-api/external/XKT019?response_format=geojson&z=14&x=14472&y=6371" > XKT019.geojson
```
