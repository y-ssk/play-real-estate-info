## 1. 概要
- 振り分け: タイル配信（`docs/02_architecture.md` 第3節。XKT 系=GISデータ→タイル配信。生活環境・周辺施設レイヤー）
- 形式: GISデータ（GeoJSON / バイナリベクトルタイル pbf）。XYZ タイル方式で取得
- 取得粒度: **中学校区の区域ポリゴン**。タイル（z/x/y 指定。ズーム 11〜15）＋ `administrativeAreaCode` で絞り込み
- 内容: 公立中学校の通学区域。XKT004（小学校区）の中学校版。タグ体系は `A32_###`（XKT004 は `A27_###`）でフィールド構成は同一
- エンドポイント: `https://www.reinfolib.mlit.go.jp/ex-api/external/XKT005?<パラメータ>`
- 認証: ヘッダ `Ocp-Apim-Subscription-Key: <APIキー>`（キーは環境変数 `MLIT_API_KEY`。**AIは値に触れない**）
- エンコード: 原文に gzip/`--compressed` の記載なし（使用例にもオプションなし）。要確認
- 座標系: 出力例の CRS は `urn:ogc:def:crs:EPSG::6668`（JGD2011 地理座標系）

## 2. リクエストパラメータ
| パラメータ | 内容 | 形式 | 必須 | 備考 |

| response_format | 応答形式 | geojson / pbf | ○ | geojson…GeoJSON応答 / pbf…バイナリベクトルタイル応答 |

## 3. レスポンス（出力）
包み構造: GeoJSON `FeatureCollection`（`name` は `junior_high_school_district`。`crs` は EPSG:6668）。`geometry.type` は `Polygon`（出力例）。タグ命名は `A32_###` コード系。全項目文字列型。

各 Feature の `properties`（タグ）:

| タグ名 | 内容 | データ型 | データ例 | 備考 |
|---|---|---|---|---|
| A32_001 | 行政区域コード | 文字列型 | 12226 | 5桁。リクエストの `administrativeAreaCode` に対応 |
| A32_002 | 設置主体 | 文字列型 | 富津市 | |
| A32_003 | 学校コード | 文字列型 | C112210002681 | 学校の識別コード（**先頭 `C`**。XKT004 小学校は `B` 始まり＝校種で接頭辞が異なる模様。要確認） |
| A32_004_ja | 名称 | 文字列型 | 富津中学校 | `_ja` サフィックス |
| A32_005 | 所在地 | 文字列型 | 富津市下飯野1135 | |

- ※ 出力例の `properties` には IF表に無い内部フィールド **`_id`・`_index`（例: `bs004_junior_high_school_district_202406281735`）が含まれる**（要確認＝未文書・依存しない方が安全）。並び順は IF 表順と不一致（キー名参照が前提）。
- ※ ジオメトリは通学区域の面（Polygon）。校舎位置の点ではない。

## 4. 使用例
リクエスト（Windows コマンドプロンプト。GeoJSON取得）:
```
curl -H "Ocp-Apim-Subscription-Key:{発行されたAPIキー}" "https://www.reinfolib.mlit.go.jp/ex-api/external/XKT005?response_format=geojson&z=14&x=14555&y=6472" > XKT005.geojson
```
レスポンス例（GeoJSON。座標列が膨大なため `coordinates` は中略。構造・CRS・properties は原文どおり、Feature 1件分を示す）:
```
{
  "type": "FeatureCollection",
  "name": "junior_high_school_district",
  "crs": { "type": "name", "properties": { "name": "urn:ogc:def:crs:EPSG::6668" } },
  "features": [
    {
      "type": "Feature",
      "geometry": { "type": "Polygon", "coordinates": [ [ [139.81198489665985, 35.30638328050776], ... ] ] },
      "properties": {
        "_id": "0TD-XZABrlAdLUL0Zq9R",
        "_index": "bs004_junior_high_school_district_202406281735",
        "A32_001": "12226",
        "A32_002": "富津市",
        "A32_003": "C112210002681",
        "A32_004_ja": "富津中学校",
        "A32_005": "富津市下飯野1135"

  ]
}
```
