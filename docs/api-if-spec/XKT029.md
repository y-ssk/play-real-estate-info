## 1. 概要
- 振り分け: タイル配信（`docs/02_architecture.md` 第3節。XKT 系=GISデータ→多くがタイル配信。防災コアの一枚）
- 形式: GISデータ（GeoJSON / バイナリベクトルタイル pbf）。**ポリゴン＋ライン**（原文: 一部地域にラインが含まれる）。XYZ タイル方式で取得
- 取得粒度: タイル（z/x/y 指定。ズーム **11〜15**＝これまでで最広）
- エンドポイント: `https://www.reinfolib.mlit.go.jp/ex-api/external/XKT029?<パラメータ>`
- 認証: ヘッダ `Ocp-Apim-Subscription-Key: <APIキー>`（キーは環境変数 `MLIT_API_KEY`。**AIは値に触れない**）
- エンコード: 原文に gzip/`--compressed` の記載なし（使用例にもオプションなし）。要確認
- 座標系: 出力例の CRS は `urn:ogc:def:crs:EPSG::6668`（JGD2011 地理座標系。XKT026/028 と同じ）

## 2. リクエストパラメータ
| パラメータ | 内容 | 形式 | 必須 | 備考 |
|---|---|---|---|---|
| response_format | 応答形式 | geojson / pbf | ○ | geojson…GeoJSON応答 / pbf…バイナリベクトルタイル応答 |
| z | ズームレベル（縮尺） | 整数 | ○ | **11（市）〜15（詳細）** で指定可能。値が大きいほど高ズーム（カバー領域は狭い） |
| x | タイル座標のX値 | 整数 | ○ | XYZ方式のX値 |
| y | タイル座標のY値 | 整数 | ○ | XYZ方式のY値 |

制約（※注記）:
- XYZ方式の詳細は GSI の確認ツール（上記参照URL）を参照。
- z は 11〜15 で指定可能。

## 3. レスポンス（出力）
包み構造: GeoJSON `FeatureCollection`（`response_format=geojson` の場合。例の `name` は `sediment_disaster_alert_area`）。`response_format=pbf` ではバイナリベクトルタイル。
- **`geometry.type` は `Polygon` と `LineString` が混在**（同一レスポンス内に両方の Feature。一部地域がライン表現）。

各 Feature の `properties`（タグ）:

| タグ名 | 内容 | データ型 | データ例 | 備考 |
|---|---|---|---|---|
| A33_001 | 現象の種類 | 整数型 | 1 | コード値。定義は原典データ項目リンク参照（未確認） |
| A33_002 | 区域区分 | 整数型 | 1 | コード値。定義は原典データ項目リンク参照（未確認） |
| A33_003 | 都道府県コード | 文字列型 | 34 | |
| A33_004 | 区域番号 | 文字列型 | Ⅱ-1-4279-1 | ローマ数字・記号を含む |
| A33_005 | 区域名 | 文字列型 | 才ノ原1543(4279-1) | |
| A33_006 | 所在地 | 文字列型 | 広島市安佐北区安佐町大字毛木 | |
| A33_007 | 公示日 | 文字列型 | 2018/03/15 | 日付だが文字列型（`YYYY/MM/DD`） |
| A33_008 | 特別警戒未指定フラグ | 整数型 | 0 | コード/フラグ値。定義は原典データ項目リンク参照（未確認） |

- ※ 出力例の `properties` には上記に加え、IF表に無い内部フィールド **`_id`・`_index`（例: `bs031_sediment_disaster_alert_area_202508051425`）が含まれる**（XKT026/028 と同様。要確認＝未文書・依存しない方が安全）。
- ※ 整数型コード（`A33_001`/`A33_002`/`A33_008`）は意味が原典リンク依存。凡例なしには表示・判定に使えない。

## 4. 使用例
リクエスト（Windows コマンドプロンプト。GeoJSON取得）:
```
curl -H "Ocp-Apim-Subscription-Key:{発行されたAPIキー}" "https://www.reinfolib.mlit.go.jp/ex-api/external/XKT029?response_format=geojson&z=11&x=1777&y=814" > XKT029.geojson
```
