# XKT016. 国土数値情報（災害危険区域）API

> MLIT 不動産情報ライブラリ API の IF 定義（公式マニュアルからの生コピペを構造化したもの）。
> 転記のみ。原文で確認できない項目は「未確認」と明記。実装着手前に本書を最終確認する。

## 1. 概要
- 振り分け: タイル配信（`docs/02_architecture.md` 第3節。XKT 系=GISデータ→多くがタイル配信。防災コアの一枚）
- 形式: GISデータ（GeoJSON / バイナリベクトルタイル pbf）。XYZ タイル方式で取得
- 取得粒度: タイル（z/x/y 指定。ズーム 11〜15）。**加えて `administrativeAreaCode`（代表行政コード）で絞り込み可**＝防災タイル系で初めて属性フィルタを持つ
- エンドポイント: `https://www.reinfolib.mlit.go.jp/ex-api/external/XKT016?<パラメータ>`
- 認証: ヘッダ `Ocp-Apim-Subscription-Key: <APIキー>`（キーは環境変数 `MLIT_API_KEY`。**AIは値に触れない**）
- エンコード: 原文に gzip/`--compressed` の記載なし（使用例にもオプションなし）。要確認
- 座標系: 出力例の CRS は `urn:ogc:def:crs:EPSG::6668`（JGD2011 地理座標系。XKT026/028/029 と同じ）

## 2. リクエストパラメータ
| パラメータ | 内容 | 形式 | 必須 | 備考 |
|---|---|---|---|---|
| response_format | 応答形式 | geojson / pbf | ○ | geojson…GeoJSON応答 / pbf…バイナリベクトルタイル応答 |
| z | ズームレベル（縮尺） | 整数 | ○ | 11（市）〜15（詳細）で指定可能。値が大きいほど高ズーム（カバー領域は狭い） |
| x | タイル座標のX値 | 整数 | ○ | XYZ方式のX値 |
| y | タイル座標のY値 | 整数 | ○ | XYZ方式のY値 |
| administrativeAreaCode | 代表行政コード | NNNNN（数字5桁） | （任意。原文の必須欄は空） | 複数指定はカンマ区切り（例: `administrativeAreaCode=01101,13102`）。コードは AdminiBoundary_CD.xlsx 参照 |

制約（※注記）:
- XYZ方式の詳細は GSI の確認ツール（上記参照URL）を参照。
- z は 11〜15 で指定可能。
- `administrativeAreaCode` の必須/任意は原文の必須欄が空のため**任意と判断**（要確認）。

## 3. レスポンス（出力）
包み構造: GeoJSON `FeatureCollection`（`response_format=geojson` の場合。例の `name` は `disaster_risk_area`）。`response_format=pbf` ではバイナリベクトルタイル。

各 Feature の `properties`（タグ）:

| タグ名 | 内容 | データ型 | データ例 | 備考 |
|---|---|---|---|---|
| A48_001 | 都道府県名 | 文字列型 | 愛知県 | |
| A48_002 | 市町村名 | 文字列型 | 名古屋市 | |
| A48_003 | 代表行政コード | 文字列型 | 23100 | リクエストの `administrativeAreaCode` に対応 |
| A48_004 | 指定主体区分 | 整数型 | 2 | コード値。定義は原典データ項目リンク参照（未確認） |
| A48_005_ja | 区域名 | 文字列型 | 臨海部防災区域(第3種) | タグ名に `_ja` サフィックス（多言語の含み。`_en` 等の有無は未確認） |
| A48_006 | 所在地 | 文字列型 | 熱田区のうち…（長文・カンマ区切りで複数区域） | |
| A48_007 | 指定理由コード | 整数型 | 3 | コード値。対応名称は `A48_007_name_ja` |
| A48_007_name_ja | 指定理由 | 文字列型 | 水害（河川・海） | `A48_007` の名称（凡例がインラインで付く） |
| A48_008_ja | 指定理由詳細 | 文字列型 | 高潮,出水 | `_ja` サフィックス |
| A48_009 | 告示年月日 | 文字列型 | 2007-10-01T00:00:00 | **ISO 8601 形式の日時文字列**（XKT029 の `YYYY/MM/DD` とは別形式） |
| A48_010 | 告示番号 | 文字列型 | 名古屋市告示第362号 | |
| A48_011 | 根拠条例 | 文字列型 | 名古屋市臨海部防災区域建築条例 | |
| A48_012 | 面積 | 実数型 | 1275 | **実数型**（これまでの整数/文字列と異なる新型。単位は未確認＝㎡/ha 等） |
| A48_013 | 縮尺 | 文字列型 | （空） | 出力例は空文字 |
| A48_014 | その他 | 文字列型 | 1階床高N・P+1メートル | |

- ※ 出力例の `properties` には上記に加え、IF表に無い内部フィールド **`_id`・`_index`（例: `bs019_disaster_risk_area_202403211850`）が含まれる**（XKT026/028/029 と同様。要確認＝未文書・依存しない方が安全）。本APIでは `_id`/`_index` が properties 先頭に並ぶ。
- ※ プロパティの**並び順は IF 表の順序と一致しない**（取り込みはキー名で参照すべき。位置依存しない）。

## 4. 使用例

```
curl -H "Ocp-Apim-Subscription-Key:{発行されたAPIキー}" "https://www.reinfolib.mlit.go.jp/ex-api/external/XKT016?response_format=geojson&z=14&x=14420&y=6483" > XKT016.geojson
```
