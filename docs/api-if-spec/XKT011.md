## 1. 概要
- 振り分け: タイル配信（`docs/02_architecture.md` 第3節。XKT 系=GISデータ→タイル配信。生活環境・周辺施設レイヤー）
- 形式: GISデータ（GeoJSON / バイナリベクトルタイル pbf）。XYZ タイル方式で取得
- 取得粒度: **施設の点（Point）**。タイル（z/x/y 指定。ズーム 13〜15）＋ 行政区域コード・福祉施設分類（大/中/小）で絞り込み
- 内容: 老人福祉施設・障害者/児童福祉施設等。**3階層の福祉施設分類コードを持ち、コード凡例の codelist URL が明記**（XKT007 保育園の `welfareFacility*` と同体系）
- エンドポイント: `https://www.reinfolib.mlit.go.jp/ex-api/external/XKT011?<パラメータ>`
- 認証: ヘッダ `Ocp-Apim-Subscription-Key: <APIキー>`（キーは環境変数 `MLIT_API_KEY`。**AIは値に触れない**）
- エンコード: 原文に gzip/`--compressed` の記載なし（使用例にもオプションなし）。要確認
- 座標系: 出力例の CRS は `urn:ogc:def:crs:EPSG::6668`（JGD2011 地理座標系）

## 2. リクエストパラメータ
| パラメータ | 内容 | 形式 | 必須 | 備考 |
|---|---|---|---|---|
| response_format | 応答形式 | geojson / pbf | ○ | geojson…GeoJSON応答 / pbf…バイナリベクトルタイル応答 |
| z | ズームレベル（縮尺） | 整数 | ○ | 13（大字）〜15（詳細）で指定可能。値が大きいほど高ズーム |
| x | タイル座標のX値 | 整数 | ○ | XYZ方式のX値 |
| y | タイル座標のY値 | 整数 | ○ | XYZ方式のY値 |
| administrativeAreaCode | 行政区域コード | NNNNN（数字5桁） | （任意。原文の必須欄は空） | 複数指定はカンマ区切り。AdminiBoundary_CD.xlsx 参照 |
| welfareFacilityClassCode | 福祉施設大分類コード | NN（数字2桁） | （任意） | 複数指定はカンマ区切り（例: `01,02`）。大分類 codelist 参照 |
| welfareFacilityMiddleClassCode | 福祉施設中分類コード | NNNN（数字4桁） | （任意） | 複数指定はカンマ区切り（例: `0101,0201`）。中分類 codelist 参照 |
| welfareFacilityMinorClassCode | 福祉施設小分類コード | NNNNNN（数字6桁） | （任意） | 複数指定はカンマ区切り（例: `020101,020102`）。小分類 codelist 参照 |

制約（※注記）:
- XYZ方式の詳細は GSI の確認ツール参照。z は 13〜15。
- 分類コードの必須/任意は原文の必須欄が空のため**任意と判断**（要確認）。

## 3. レスポンス（出力）
包み構造: GeoJSON `FeatureCollection`（`name` は `welfare_facility`。`crs` は EPSG:6668）。`geometry.type` は `Point`。タグ命名は `P14_###` コード系。
- **大/中分類はコードと名称が併出**（`P14_005`＋`P14_005_name_ja`、`P14_006`＋`P14_006_name_ja`）。小分類（`P14_007`）はコードのみ。

各 Feature の `properties`（タグ）:

| タグ名 | 内容 | データ型 | データ例 | 備考 |
|---|---|---|---|---|
| P14_001 | 都道府県名 | 文字列型 | 神奈川県 | |
| P14_002 | 市区町村名 | 文字列型 | 鎌倉市 | |
| P14_003 | 行政区域コード | 文字列型 | 14204 | 5桁 |
| P14_004_ja | 所在地 | 文字列型 | 材木座2-15-3 | |
| P14_005 | 福祉施設大分類コード | 文字列型 | 02 | 大分類 codelist 参照（観測: 02=老人福祉施設 / 99=その他の社会福祉施設等） |
| P14_005_name_ja | 福祉施設大分類名 | 文字列型 | 老人福祉施設 | `P14_005` の名称 |
| P14_006 | 福祉施設中分類コード | 文字列型 | 0203 | 中分類 codelist 参照 |
| P14_006_name_ja | 福祉施設中分類名 | 文字列型 | 老人福祉センター | `P14_006` の名称 |
| P14_007 | 福祉施設小分類コード | 文字列型 | 020302 | 小分類 codelist 参照（名称併出なし） |
| P14_008_ja | 名称 | 文字列型 | 名越やすらぎセンター | 施設名 |
| P14_009 | 管理者コード | 整数型 | 0 | コード値（定義は原典参照・要確認） |
| P14_010 | 位置正確度コード | 整数型 | 1 | コード値（位置情報の正確度。要確認） |

- ※ 出力例の `properties` には IF表に無い内部フィールド **`_id`・`_index`（例: `bs008_welfare_facility_202406281932`）が含まれる**（要確認＝未文書・依存しない方が安全）。並び順は IF 表順と不一致（キー名参照が前提）。

## 4. 使用例
リクエスト（Windows コマンドプロンプト。GeoJSON取得）:
```
curl -H "Ocp-Apim-Subscription-Key:{発行されたAPIキー}" "https://www.reinfolib.mlit.go.jp/ex-api/external/XKT011?response_format=geojson&z=14&x=14543&y=6472" > XKT011.geojson
```
