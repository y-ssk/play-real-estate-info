# XKT006. 国土数値情報（学校）API

> MLIT 不動産情報ライブラリ API の IF 定義（公式マニュアルからの生コピペを構造化したもの）。
> 転記のみ。原文で確認できない項目は「未確認」と明記。実装着手前に本書を最終確認する。

## 1. 概要
- 振り分け: タイル配信（`docs/02_architecture.md` 第3節。XKT 系=GISデータ→タイル配信。生活環境・周辺施設レイヤー）
- 形式: GISデータ（GeoJSON / バイナリベクトルタイル pbf）。XYZ タイル方式で取得
- 取得粒度: **学校の点（Point）＝施設位置**（XKT004/005 の通学区域＝面とは別。校種を分類コードで持つ）。タイル（z/x/y 指定。ズーム **13〜15**）。属性フィルタ無し
- 内容: 小学校・中学校・高校等の学校位置。校種は `P29_003`（学校分類コード）で識別
- エンドポイント: `https://www.reinfolib.mlit.go.jp/ex-api/external/XKT006?<パラメータ>`
- 認証: ヘッダ `Ocp-Apim-Subscription-Key: <APIキー>`（キーは環境変数 `MLIT_API_KEY`。**AIは値に触れない**）
- エンコード: 原文に gzip/`--compressed` の記載なし（使用例にもオプションなし）。要確認
- 座標系: 出力例の CRS は `urn:ogc:def:crs:EPSG::6668`（JGD2011 地理座標系）

## 2. リクエストパラメータ
| パラメータ | 内容 | 形式 | 必須 | 備考 |
|---|---|---|---|---|
| response_format | 応答形式 | geojson / pbf | ○ | geojson…GeoJSON応答 / pbf…バイナリベクトルタイル応答 |
| z | ズームレベル（縮尺） | 整数 | ○ | **13（大字）〜15（詳細）** で指定可能。値が大きいほど高ズーム |
| x | タイル座標のX値 | 整数 | ○ | XYZ方式のX値 |
| y | タイル座標のY値 | 整数 | ○ | XYZ方式のY値 |

制約（※注記）:
- XYZ方式の詳細は GSI の確認ツール参照。z は 13〜15。属性フィルタは無し。

## 3. レスポンス（出力）
包み構造: GeoJSON `FeatureCollection`（`name` は `school`。`crs` は EPSG:6668）。`geometry.type` は `Point`（学校位置）。タグ命名は `P29_###` コード系。型は整数/文字列が混在。

各 Feature の `properties`（タグ）:

| タグ名 | 内容 | データ型 | データ例 | 備考 |
|---|---|---|---|---|
| P29_001 | 行政区域コード | 文字列型 | 14205 | 5桁 |
| P29_002 | 学校コード | 文字列型 | B114220520022 | 先頭 `B`（小学校。XKT004/005 の学校コードと整合） |
| P29_003 | 学校分類コード | 整数型 | 16001 | コード値。対応名称は `P29_003_name_ja` |
| P29_003_name_ja | 学校分類名 | 文字列型 | 小学校 | `P29_003` の名称（凡例インライン） |
| P29_004_ja | 名称 | 文字列型 | 藤沢市立明治小学校 | |
| P29_005_ja | 所在地 | 文字列型 | 神奈川県藤沢市城南3-3-1 | |
| P29_006 | 管理者コード | 整数型 | 3 | コード値（定義は原典参照・要確認） |
| P29_007 | 休校区分 | 整数型 | 1 | コード値（1の意味＝現役/休校は原典参照・要確認。**層1で休校除外に関わる**） |
| P29_008 | キャンパスコード | 文字列型 | 00 | |
| P29_009_ja | 学校名備考 | 文字列型 | （空） | |

- ※ 出力例の `properties` には IF表に無い内部フィールド **`_id`・`_index`（例: `bs005_school_202406281740`）が含まれる**（要確認＝未文書・依存しない方が安全）。並び順は IF 表順と不一致（キー名参照が前提）。

## 4. 使用例
リクエスト（Windows コマンドプロンプト。GeoJSON取得）:
```
curl -H "Ocp-Apim-Subscription-Key:{発行されたAPIキー}" "https://www.reinfolib.mlit.go.jp/ex-api/external/XKT006?response_format=geojson&z=13&x=7269&y=3235" > XKT006.geojson
```
レスポンス例（GeoJSON。点データ。Feature 1件分を原文どおり。実際は多数）:
```
{
  "type": "FeatureCollection",
  "name": "school",

    {
```
