## 3. レスポンス（出力）
包み構造: GeoJSON `FeatureCollection`（`name` は `elementary_school_district`。`crs` は EPSG:6668）。`geometry.type` は `Polygon`（出力例）。タグ命名は `A27_###` コード系。全項目文字列型。

各 Feature の `properties`（タグ）:

| タグ名 | 内容 | データ型 | データ例 | 備考 |
|---|---|---|---|---|
| A27_001 | 行政区域コード | 文字列型 | 01236 | 5桁。リクエストの `administrativeAreaCode` に対応 |
| A27_002 | 設置主体 | 文字列型 | 北斗市立 | |
| A27_003 | 学校コード | 文字列型 | B101223600051 | 学校の識別コード |
| A27_004_ja | 名称 | 文字列型 | 上磯小学校 | `_ja` サフィックス |
| A27_005 | 所在地 | 文字列型 | 北斗市中野通200 | |

- ※ 出力例の `properties` には IF表に無い内部フィールド **`_id`・`_index`（例: `bs003_elementary_school_district_202406281727`）が含まれる**（要確認＝未文書・依存しない方が安全）。並び順は IF 表順と不一致（キー名参照が前提）。
- ※ ジオメトリは通学区域の面（Polygon）。校舎位置の点ではない点に注意。

## 4. 使用例
リクエスト（Windows コマンドプロンプト。GeoJSON取得）:
```
curl -H "Ocp-Apim-Subscription-Key:{発行されたAPIキー}" "https://www.reinfolib.mlit.go.jp/ex-api/external/XKT004?response_format=geojson&z=14&x=14592&y=6093" > XKT004.geojson
```
レスポンス例（GeoJSON。座標列が膨大なため `coordinates` は中略。構造・CRS・properties は原文どおり、Feature 1件分を示す）:
