## 1. 概要
- 振り分け: タイル配信（`docs/02_architecture.md` 第3節。XKT 系=GISデータ→多くがタイル配信。防災コアの一枚）
- 形式: GISデータ（GeoJSON / バイナリベクトルタイル pbf）。XYZ タイル方式で取得
- 取得粒度: タイル（z/x/y 指定。ズーム 11〜15）。**加えて `prefectureCode`（都道府県）/ `administrativeAreaCode`（行政コード）で絞り込み可**
- エンドポイント: `https://www.reinfolib.mlit.go.jp/ex-api/external/XKT021?<パラメータ>`
- 認証: ヘッダ `Ocp-Apim-Subscription-Key: <APIキー>`（キーは環境変数 `MLIT_API_KEY`。**AIは値に触れない**）
- エンコード: 原文に gzip/`--compressed` の記載なし（使用例にもオプションなし）。要確認
- 座標系: 出力例の CRS は `urn:ogc:def:crs:EPSG::6668`（JGD2011 地理座標系。XKT026/028/029/016 と同じ）

## 2. リクエストパラメータ
| パラメータ | 内容 | 形式 | 必須 | 備考 |
|---|---|---|---|---|
| response_format | 応答形式 | geojson / pbf | ○ | geojson…GeoJSON応答 / pbf…バイナリベクトルタイル応答 |
| z | ズームレベル（縮尺） | 整数 | ○ | 11（市）〜15（詳細）で指定可能。値が大きいほど高ズーム（カバー領域は狭い） |
| x | タイル座標のX値 | 整数 | ○ | XYZ方式のX値 |
| y | タイル座標のY値 | 整数 | ○ | XYZ方式のY値 |
| prefectureCode | 都道府県コード | NN（数字2桁） | （任意。原文の必須欄は空） | 複数指定はカンマ区切り（例: `prefectureCode=09,14`）。PrefCd.html 参照 |
| administrativeAreaCode | 行政コード | NNNNN（数字5桁） | （任意。原文の必須欄は空） | 複数指定はカンマ区切り（例: `administrativeAreaCode=01101,13102`）。AdminiBoundary_CD.xlsx 参照 |

制約（※注記）:
- XYZ方式の詳細は GSI の確認ツール（上記参照URL）を参照。
- z は 11〜15 で指定可能。
- `prefectureCode` / `administrativeAreaCode` の必須/任意は原文の必須欄が空のため**任意と判断**（要確認）。併用可否も未確認。

## 3. レスポンス（出力）
包み構造: GeoJSON `FeatureCollection`（`response_format=geojson` の場合。例の `name` は `landslide_prevention`）。`response_format=pbf` ではバイナリベクトルタイル。
- **タグ命名が他の防災レイヤー（`A##_###` コード）と異なり、説明的な snake_case 英語**（`prefecture_code` 等）。＝レイヤー間で属性キーの命名規則が統一されていない（取り込みマッピングはレイヤー別に必要）。

各 Feature の `properties`（タグ）:

| タグ名 | 内容 | データ型 | データ例 | 備考 |
|---|---|---|---|---|
| prefecture_code | 都道府県コード | 文字列型 | 22 | |
| group_code | 行政コード | 文字列型 | 22100 | リクエストの `administrativeAreaCode` に対応 |
| city_name | 市町村名 | 文字列型 | 静岡市 | |
| region_name | 区域名 | 文字列型 | 寺尾 | |
| address | 所在地 | 文字列型 | 庵原郡由比町寺尾 | |
| notice_date | 告示年月日 | 文字列型 | 1986/08/02 | `YYYY/MM/DD`（XKT029 と同形式。XKT016 の ISO 日時とは別形式） |
| notice_number | 告示番号 | 文字列型 | 579 | |
| landslide_area | 指定面積（ha） | 文字列型 | 0.0(ha) | **数値ではなく単位込みの文字列**（`0.0(ha)`）。XKT016 A48_012 は実数型だったのと対照的 |
| charge_ministry_code | 所管省庁コード | 整数型 | 3 | コード値。対応名称は `charge_ministry_name` |
| prefecture_name | 都道府県名 | 文字列型 | 静岡県 | |
| charge_ministry_name | 所管省庁名 | 文字列型 | 林野庁 | `charge_ministry_code` の名称（凡例がインラインで付く） |

- ※ 出力例の `properties` には上記に加え、IF表に無い内部フィールド **`_id`・`_index`（例: `bs024_landslide_prevention_202412161233`）が含まれる**（防災系共通。要確認＝未文書・依存しない方が安全）。並び順は IF 表順と不一致（キー名参照が前提）。

## 4. 使用例
リクエスト（Windows コマンドプロンプト。GeoJSON取得）:
```
curl -H "Ocp-Apim-Subscription-Key:{発行されたAPIキー}" "https://www.reinfolib.mlit.go.jp/ex-api/external/XKT021?response_format=geojson&z=14&x=14497&y=6485" > XKT021.geojson
```
