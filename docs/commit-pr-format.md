# コミット / PR の様式

> 参照チェーン：`CLAUDE.md` → 本書 → スキル `commit-pr-format`。
>
> 様式の**実体はスキル `commit-pr-format` に隠蔽**している（`.claude/skills/commit-pr-format/SKILL.md`）。
> コミットを打つ前・PR を作成記述する前に、そのスキルを参照して様式に沿わせること。
> スキルにすることで本体は呼び出し時のみロードされ、ドキュメント層は薄く保てる。
>
> 暫定。記録様式（ADR・学習メモを含む全体）の確定は Step D（`99_decision-register.md`）。
