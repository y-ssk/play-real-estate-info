# ADR-0006: 災害分野の指標定義 — 面積率に統一・コアは両用・避難場所と履歴の扱い

- ステータス: 承認
- 日付: 2026-06-24
- 関連: `ADR-0005`（指標化の高度）/ `docs/99`（バックログ優先1・保留「防災レイヤーの扱い」）/ `docs/01`§3 / `docs/02`§3§8 / `docs/api-if-spec/`（XKT026/027/028/029/025/020/021/022/016, XST001, XGT001）

## なぜ（背景・課題）

価値定義（優先1）の最初の分野として、共通土台かつ価値の中心である「災害」を、手持ちのMLIT防災APIで具体的に何の数値で表すかを決める必要があった。
同時に `docs/99` の保留「防災レイヤーの扱い（純タイル配信か／指標化のため両用か）」のトリガー（P2でデータモデリング方針を詰める時）が充足したため、ここで決着させる。

前提の整理：MLIT API側が市区町村コードでの絞り込みに対応していなくても、ポリゴンをPostGISに取り込み市区町村ポリゴンへ空間結合すれば「該当面積率」は計算できる。論点は「計算できるか」ではなく「MVPで集計値を持つ価値があるか／塗り絵だけで十分か」。

## 結論（決定）

1. **防災は「両用」を基本**（生レイヤー＝塗り絵 と 市区町村集計値 の両方）。`ADR-0005` の2層そのもの。ただし全11種に集計値は作らない（過剰）。コアだけ集計、周辺は塗り絵＋カルテ件数。＝保留「防災レイヤーの扱い」の決着。

2. **集計指標は「該当面積率(%)」に統一**。単位ポリゴン（市区町村）に空間結合し、交差面積÷単位面積。
   - **浸水深などのランクは数値に混ぜない**（深さで重みづけ＝主観的な点数化に滑る。v2のスコアリングに属するため避ける）。
   - 深さは塗り絵側で色の濃淡として見せる。必要なら深さ帯ごとの面積率を「別々の事実」として並べる（重みをかけないので点数化にならない）。
   - この型は単位を市区町村↔メッシュで差し替えても同じ計算が効く（v1のメッシュ移行に強い。`docs/02`§8）。

3. **振り分け**：
   - 面塗り集計を持つ（両用）＝**洪水 XKT026・津波 XKT028・土砂 XKT029・液状化 XKT025**。すべて該当面積率。土砂のラインジオメトリは塗り絵のみ、液状化は高傾向メッシュの面積率。
   - 塗り絵＋カルテ件数＝高潮 XKT027（沿岸限定・座標系も別）・災害危険区域 XKT016・地すべり XKT021・急傾斜地 XKT022・盛土造成地 XKT020・災害履歴 XST001。

4. **避難場所 XGT001 は面塗りから外し、塗り絵（点）＋カルテ件数**。位置づけは利便でなく災害側（防災への備え）。理由：数が多くても住居近接や災害種別対応は不明で、面で比べる数値には向かない。人口あたり算出は人口データ依存も増える。

5. **災害履歴 XST001 はカルテ件数のまま（面塗りにしない）**。種類・年代の内訳つき。理由：国土調査の記録は網羅性にムラがあり「件数0＝安全」とは限らない。地図全体を件数で色分けすると記録の薄い街が安全に見え誤読を招く。実データで網羅性を確認できたら面塗りへ格上げ可。

## 検討した代替案と捨てた理由

- **浸水深を数値に混ぜる（深さ重みづけの面積率）** … 1つの数値に深刻さを織り込めるが、「5mは0.5mの何倍危険か」の重みが主観的な決め＝点数化。客観性・透明性が崩れ `ADR-0005` と矛盾。深さは塗り絵と「別事実の面積率」で表現する方針に。
- **防災を純タイル配信のみにする** … ETL負担は最小だが、価値の中心である災害で市区町村集計がゼロだと「面で比べる」が立たない。差別化の核を損なうため不採用。
- **全11ハザードを面塗り集計にする** … 過剰。周辺ハザードは局所的・網羅性にムラがあり、面塗りの価値が低い割に検証コストが高い。コアのみ集計に絞る。
- **避難場所・災害履歴を面塗りに上げる** … いずれも面で比べる数値としては誤読リスク（網羅性・近接性）が大きい。カルテ・塗り絵で扱う。

## 影響（結果・トレードオフ）

- `docs/02`§3 の「XKT防災＝多くがタイル配信」という当初整理を更新：コア4種（洪水・津波・土砂・液状化）はETL＋タイルの両用になる。
- 集計の実装は空間結合基盤（優先2）に依存。本ADRは「何の数値にするか」の定義まで。
- 集計を「単位ポリゴンへの空間結合」で統一したことで、市区町村→メッシュの単位差し替えが容易（メッシュ移行に強い設計方針。全分野に適用）。
- 取り込み時の既知の注意（IF定義より）：CRS不一致（XKT027=CRS84、他EPSG:6668）、キー名揺れ（A##系/snake_case、market_code/group_code/city_code）、ジオメトリ型混在（土砂=line＋polygon、盛土=polygon＋multipolygon）、日付形式の揺れ。取り込みで正規化・吸収する。
- 残ブロック：利便・相場・将来・教育の指標定義（次）、カルテの中身、比較体験。
