# ADR-0011: カルテの中身 — 骨組み・相場の統計セット・出典/欠損/推計の明示

- ステータス: 承認
- 日付: 2026-06-24
- 関連: `ADR-0005`〜`ADR-0010`（指標化の高度・各分野）/ `docs/99`（バックログ優先1・保留「出典表示」「エラー/データ欠損UI」「指標の見せ方UI」）/ `docs/01`§3 / `docs/02`§4

## なぜ（背景・課題）

カルテ（街を選ぶと出る詳細パネル）の中身を確定する。中身の大半はブロック2（各分野の指標）で分野ごとに決定済み（面積率・件数・推移グラフ等）。本ADRは残る3点＝(a)骨組み・(b)相場の統計セット（`ADR-0008` から持ち越し）・(c)出典/欠損/推計の明示を確定する。

## 結論（決定）

### (a) 骨組み（情報設計）
- **順序**：共通土台を上に〔災害 → 利便〕、割れる分野を下に〔相場 → 将来 → 教育〕。全層が必ず見るものを上に（`docs/01`§3）。
- **各分野は2段**：見出しの数値（地図の色分けに使った代表値。例：洪水の面積率、地価の中央値、人口増減率）＋詳細（カルテ固有の件数・推移グラフ・複数統計）。
- 出典・データなし・推計を各項目に添える。
- この1街ぶんの骨組みを、比較（ブロック4・v1）でそのまま使い回せる形にする。

### (b) 相場の統計セット
- **公的地価（背骨）**：住宅地の単価の中央値（最新年）＋変動率＋年次の推移グラフ。
- **実取引（実勢）**：物件種別ごと（中古マンション／土地・戸建て 等、混ぜない）に、**中央値＋平均＋25〜75%の幅＋件数**（件数が少なければ「参考値」と明示）。
- **ヒストグラム（分布の形）はv1**。
- **MVP採否の基準**：① 読者の別々の問い（代表・ばらつき・確からしさ・偏り）に答える、② 件数が少なくても破綻せず弱さが出る、③ 追加のグラフ部品を要さない。中央値・幅・件数・平均は満たす。ヒストグラムは③に反し、件数の薄い街では形が出せず誤読の恐れ（②も弱い）→ v1。

### (c) 出典・データなし・推計の明示
- **出典（法的要件）**：全項目にMLIT/国土数値情報の該当データ名を紐づけて保持（ETL既決要件）。表示はカルテ末尾の「出典」欄＋各分野に小さく明記。必ず出す。
- **データなしは3つを区別**（空欄や0でごまかさない）：
  - データなし（対象外・未整備。例：学区未整備の自治体）
  - 該当なし＝値が0（データはあり値がゼロ。例：浸水想定区域0%、駅0）
  - 秘匿（将来人口で小人口メッシュが非公開）
  「危険ゼロ」と「調べていない」を混同させないため見た目で区別する。
- **推計（予測）の明示**：将来人口の数値・グラフに「推計（予測）」と基準年を添え、実績（地価・件数等）と見た目で区別する。

## 検討した代替案と捨てた理由

- **割れる分野を上に置く** … 全層が必ず見る共通土台（災害・利便）を上が自然。
- **代表値を中央値だけにする** … 実態（ばらつき）と確からしさ（件数）が見えない。複数統計＋件数を出す。
- **ヒストグラムをMVPに入れる** … グラフ部品が要り、件数の薄い街では誤読。v1へ。
- **データなしを空欄や0で表現** … 「危険ゼロ」と「未調査」を混同させ誤導。3区別を明示。

## 影響（結果・トレードオフ）

- 出典・欠損の明示はETL要件（`docs/02`§4 出典保持・欠損検知）とUI（保留：出典表示・エラー/欠損UI・指標の見せ方UI）に引き継ぐ。3区別はETLの欠損検知の設計入力。
- 推計の明示は `ADR-0009` と連動。
- カルテの骨組みは比較ビュー（v1）で再利用する前提。
- 残ブロック：比較体験（ブロック4）。
