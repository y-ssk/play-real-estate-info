# ADR-0029: 絞り込みパネルは左上アイコン1つで開閉するドロワー（PCは移動なし・モバイルは閉アイコンのみ移動可）。カルテは右側固定

- ステータス: 承認
- 日付: 2026-06-29
- 関連: `DESIGN`§2（地図UIパターン＝更新元）・`docs/05`§3（S1内 絞り込みパネル）・`ADR-0028`（④再定義＝絞り込みは地図ハイライトに徹する）・`ADR-0018`（パネル開閉＝状態）・`docs/99`「実装スライス」④/#59

## なぜ（背景・課題）

`DESIGN`§2 の「③開閉式パネル」は **閉=地図全面／開=固定領域** までしか定めておらず、開いたパネルの **置き場と可動性** を決めていなかった。④（Issue #57・PR #58 で dev 反映）の絞り込みパネルは現状「固定領域」で、層4目視でオーナーから「**絞り込み中も地図を広く使いたい。端から出し入れしたい**」との要望が出た。

当初（2026-06-28）は「可動ドロワー＝端から開閉＋ヘッダ掴みで移動」で実装したが（PR #60）、**層4目視で挙動が破綻**した：(1) ウィンドウ左上のトグルとパネルが同じ位置・同じアイコンで重なり「開閉ボタンが2つ・どちらが効くか分からない」状態、(2) 飾りで置いた重複アイコンが非ボタンで「同じアイコンなのに片方は何もしない」、(3) 移動アニメ（transition）が常時かかりドラッグがゴムのように遅れて追従、(4) 任意位置へ動かせるのが「真ん中に来ると邪魔」。**設計（移動可能）が UI の見分けと操作の素直さを壊していた**。再壁打ちでオーナーが構えを定め直した。

## 結論（決定）

絞り込みパネル（F3）は **トグル1つ（モーダル左上の角の丸いアイコン）で開閉するドロワー**。PC では動かさない。

- **トグルは1つ＝モーダル左上の角の丸いアイコン**（ウィンドウ左上の別ハンドルは廃止＝重複の元）。
  - **閉**：その左上アイコンだけが見える。押すと開く。ほかは出さない（地図全面）。
  - **開**：左からスライドして出たパネル（サイズは従来感）。左上アイコンはその位置に留まり、**押すと閉じる**。
- **閉じられるのは2つだけ＝「左上アイコン」と「閉じるボタン(X)」**。それ以外（本体・スライダー）を触っても閉じない。
- **PC ではパネルを移動しない（固定）**。ヘッダ掴み・本体ドラッグによる移動は採らない（任意位置へ動かせると邪魔・操作の見分けを壊す＝層4で実証）。アニメは**開閉のスライドだけ**（移動アニメは無い）。
- **モバイル（スマホ幅）＝閉じている時のアイコンだけ移動可**（親指の届く位置へ寄せる）。開いている間は動かさない。**実装はモバイル対応（ボトムシート・`DESIGN`§2「PC実装後」）の段で**＝PC スライスでは入れない（先回りしない）。
- **カルテパネル（F5）＝右側固定のまま**（可動化しない・収束フェーズの安定）。左=探索（左ドロワー）／右=収束（右固定）の左右対比。

開閉は **“状態”であって画面遷移ではない**（`ADR-0018`・`docs/05`§4 遷移図は不変）。状態の真実は store（開閉）。モーション用途トークン（`--motion-base 200ms`・`prefers-reduced-motion`）に従う。

## 検討した代替案と捨てた理由

- **可動ドロワー（端から開閉＋ヘッダ掴み or 本体ドラッグで任意位置へ移動）** → 採って（PR #60）層4で破綻＝捨てた。トグルとパネルの重なり・重複アイコン・常時アニメで「見た目と挙動が一致しない」。任意移動は「真ん中に来て邪魔」。**周辺UI部品に対し作り込みが過剰**（本丸＝地図/データ・`CLAUDE.md`）で、得る価値（地図を広く使う）は「固定の開閉ドロワー」で十分達成できる。
- **本体ドラッグは地図のパンへ通す（移動はヘッダのみ）** → 上記の一部として捨てた。PC で移動自体を採らないため不要。地図はパネルの外を掴めばパンできる。
- **カルテも可動化して統一** → 捨てた。カルテは「読み込む」収束フェーズの安定が要る。役割で置き方を分ける（左ドロワー／右固定）。

## 影響（結果・トレードオフ）

- **得るもの**：絞り込み中に地図を全面へ戻せる（開閉だけ）。**トグル1本化＋固定**で「どれを押すと何が起きるか」が一意＝見た目と挙動が一致（層4指摘の解消）。実装が大幅に軽くなる（ドラッグ・座標 store・クランプ・移動アニメ制御が不要）。
- **トレードオフ**：PC で位置を動かせない（が、オーナー判断＝移動はむしろ邪魔）。モバイルの「閉アイコン移動」は後送り（モバイル対応時に実装）。
- **正の更新**：`DESIGN`§2（パネルの置き方を「左上アイコンで開閉するドロワー・PC固定／モバイルは閉アイコン移動・後送り」へ）・`docs/05`§3（S1内 絞り込みパネル注記）。
- **撤回（PR #60 の実装から外す）**：可動ドロワーのドラッグ実装＝ヘッダの pointer 捕捉・浮かせ量 `offset`・`clampDrawerOffset`・移動アニメ。ウィンドウ左上の別トグル。飾りの重複アイコン。
- **影響なし**：`ADR-0028`（絞り込み=ハイライト→カルテ）・`ADR-0011`（カルテ中身）・`ADR-0018`（開閉=状態。位置 store は不要になり開閉のみ）・④の純ロジック（`filtering.ts`）。ドロワーは絞り込みUIの“器”でロジックは不変。
- **規約例外（フォーカストラップを入れない）は維持**：melta `prohibited.md:70` はモーダル Drawer 前提のフォーカストラップを要求するが、本パネルは**非モーダル小窓**（背面の地図を操作させる）ゆえトラップを入れない＝矛盾する。代わりに非モーダルとして相応の a11y を備える＝**ESC で閉じる／閉じたらフォーカスを起点のトグルへ戻す**（`no-unjustified-convention-exceptions`＝例外は根拠なく残さない）。
- **スライス**：④の機能の核（#57/PR #58）とは分けたフォロー増分（#59・PR #60）＝レビュー単位を濁さない。PR #60 はこの改訂に合わせて実装を簡素化してから仕上げる（未マージ）。
