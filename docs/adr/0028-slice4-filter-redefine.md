# ADR-0028: ④絞り込みの再定義＝地図ハイライト主体・並べ替え一覧表の母体をピン候補へ

- ステータス: 承認
- 日付: 2026-06-28
- 関連: `docs/99`「実装スライス」④/#6・`ADR-0012`（面で比べる体験＝更新元）・`docs/01`§3（広く探す→ピン→比較）・`docs/05`§1§2§3§4・スライス#42（クローズ）

## なぜ（背景・課題）

スライス④の初版（#42）は「条件で絞り込み→該当を地図ハイライト＋**並べ替えできる一覧表**で見る」を実装したが、層4目視（オーナー・2026-06-27）で「**絞り込みが一覧表示で終わりなら不要（少なくとも今の形式では）。結果はカルテ/ピンへ繋ぐ方向で再定義**」と差し戻され #42 はクローズした。

問題の核は「絞り込み該当区の全部を並べた表が dead-end（行き止まり）になっていて、その先の行動（詳細を見る・候補を残す）へ繋がっていない」こと。`ADR-0012` は「面で比べる」MVP を **色分け地図＋絞り込み＋ピン留め＋並べ替え一覧表** と定めたが、その4要素を **どう一つの導線に繋ぐか** は決めていなかった（要素の列挙にとどまった）。本 ADR はその導線を確定する。

## 結論（決定）

`docs/01`§3 が既に定める **「広く探す→ピン→比較」** のフローに素直に乗せる。

- **絞り込み（F3）は「広く探す」段に徹し、地図ハイライトで該当を示す**。条件は AND・重みづけしない（`ADR-0012`）。該当区を地図上で強調し、非該当を沈める（値の色とは別チャネル＝`ADR-0005`）。
- **独立した「該当全件の一覧表」は持たない**（dead-end を根絶）。該当区は**地図クリックでカルテ（F5・③開閉式・実装済）**へ、カルテから**ピン留め（F6）**へ繋ぐ。
- **「並べ替え一覧表（F7）」は『比較』段＝ピン留めした候補に対して出す**。すなわち F7 の母体を **『絞り込み該当区の全部』から『ピン留めした候補』へ精緻化**し、**F7 はピン一覧（F6/F7 統合）に置く**。

スライス割付：
- **再定義④＝「絞り込み→地図ハイライト→（クリックで）カルテへ繋ぐ」**（一覧表なし）。カルテは実装済みゆえ④は #6 ピンに依存せず単独で層4検証できる。
- **#6 ピン留め＝ピン留め＋ピン一覧（並べ替え＝比較）**（F6/F7）。F7 はここに移設。
- #42 の純ロジック `lib/filtering.ts`（突き合わせ・AND絞り込み・安定並べ替え）は再利用する。
- #42 層4指摘 2〜6（範囲スライダー／%・符号表示／配色コーラル・共通部品／Lucide ソートアイコン／一覧ヘッダ固定）は「作り方の要件」＝該当スライスの完了条件へ持ち越す（仕様の分岐ではない。共通部品土台はスライス3.5/`ADR-0027`で整備済み）。

## 検討した代替案と捨てた理由

- **案B（絞り込み結果の一覧表を残し、終着点でなく導線にする＝各行→カルテ／行ごとにピン／並べ替え維持）** → 捨てた。`ADR-0012` の「並べ替え一覧表」を最小変更で保てるが、オーナーが疑問視した「該当全件の表そのもの」を温存する。`docs/01`§3 では並べ替えで比べる行為は本来「比較」段（ピン候補）に属し、絞り込み直後に全件を表でランキングするのは「広く探す」段に表を二重に持つことになる。UI量も最大（行アクション＋ヘッダ固定＋ピンボタンが全部この表に乗る）。
- **絞り込み結果を一括でピン候補に流し込む案** → 見送り。絞り込み該当とピン（ユーザーが意思で残した候補）を混同させる。ピンは「自分が選んだ」意味を持たせたい（比較の母集団）。

## 影響（結果・トレードオフ）

- **得るもの**：dead-end の解消。地図が「面で比べる」表面そのものになり、フローが `docs/01`§3 と一致。一覧は「自分が選んだ候補を並べ替えて比べる」明確な役割になる。④を小さく作り直せ、F7 を #6 に集約できる。
- **トレードオフ**：「条件に合う街を表でざっと一覧する」導線は弱まる（代わりに地図ハイライト＋ピン）。全件の網羅的ランキングが要るとの声が将来出たら、比較ビュー（F10・v1）や検索結果表として別途検討する（MVPでは持たない）。
- **正の更新**：`docs/05`（§1 起点(c)・§2 F3/F7・§3 S1内・§4 遷移図）を本決定に合わせて更新。`ADR-0012` は凍結根拠ゆえ書き換えず、本 ADR が「並べ替え一覧表の母体」を更新する関係（索引でクロスリンク）。
- **影響なし**：`ADR-0005`（値の色チャネル）・`ADR-0011`（カルテ）・`ADR-0018`（状態＝Zustand）はそのまま。ハイライトは値の色と別チャネル・状態の真実は store（#42 の設計を踏襲）。
