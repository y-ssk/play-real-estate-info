# ADR-0031: 絞り込みパネルは開いても「絞り込み」ボタンを残し、その直下にパネルを出す（ボタン再クリック/×/ESC で閉じる）。ADR-0029 の「開いたらボタンを隠す」を更新

- ステータス: 承認
- 日付: 2026-07-05
- 関連: `ADR-0029`（更新元＝絞り込みパネルの構え）・`DESIGN`§2・`docs/05`§3・`docs/99`「絞り込みパネルの構え」／実装スライス 4c(#69)・`ADR-0028`（④＝絞り込みは地図ハイライト）

## なぜ（背景・課題）

`ADR-0029` は絞り込みパネルを「左操作列ボタンで開閉する左オーバーレイ・PC固定」と定め、**開いている間はトグルボタンを隠し、同じ場所にパネルを出す**（閉↔開で同じ場所が姿を変える）とした。狙いは、可動ドロワー破綻時に「開くボタンと閉じるボタンが2つに見える」混乱を避けること。

4c（#69・PR #70＝パネル原点を指標トグルの下 top:84 へ）を層4目視したオーナーから、**「条件を確認して閉じようとするとき、ヘッダの×までが遠い。パネルが『絞り込み』ボタンの直下に来て、×がボタンの近くにある方がよい」**との要望。開閉の起点（ボタン）が消えてパネル上端の×だけになるより、ボタンを視野に残しその直下にパネルが続く方が、開閉の動線が短く分かりやすい。

## 結論（決定）

絞り込みパネル（F3）は、**開いている間も「絞り込み」ボタンを残し（active 表示）、そのボタンの直下にパネルを出す**。

- **ボタンは隠さない**：閉＝「絞り込み」ボタンのみ／開＝ボタンは残り（押されている active 表示）、**その直下にパネルが続く**。ボタンとパネルの×が縦に近接する。
- **閉じる手段＝「絞り込み」ボタン再クリック・× ・ESC**（`ADR-0029` の×/ESC に「ボタン再クリック」を追加）。＝ボタンが開閉トグルとして一貫（開く/閉じる同一ボタン）。パネルヘッダの×は近接した明示の閉じ手段。
- **配置**：ボタンは従来どおり左の操作列（指標トグルの下・倍率/指標トグルと非衝突）。パネルはボタンの**下端の直下**から下へ伸びる（左端・`left:8`・左スライドは不変）。
- `ADR-0029` の他の決定（左オーバーレイ／PC固定・移動なし／左=探す・右=収束／カルテ右固定／開閉=状態／モーション用途トークン／モバイル=ボトムシート別スライス／非モーダルゆえフォーカストラップ非導入・ESC/フォーカス復帰）は**不変**。

## 検討した代替案と捨てた理由

- **ADR-0029 のまま（開いたらボタンを隠し同じ場所にパネル）** → 層4で×が遠いと不評＝捨てた。開閉起点が消えるため、閉じる動線がヘッダ×まで伸びる。
- **ボタンは開く専用のまま（閉じは×/ESCのみ・ボタン再クリック無し）** → 捨てた。ボタンを残すのに押しても閉じないのは挙動が不一致（残すなら開閉トグルが自然）。

## 影響（結果・トレードオフ）

- **得るもの**：開閉起点が常に視野に残り、×がボタン直下で近い＝閉じる動線が短い。開くボタン＝閉じるボタン（同一）で「ボタンが2つに見える」混乱はむしろ小さい（`ADR-0029` の懸念は active 表示＋近接＋同一トグル化で解消）。
- **トレードオフ**：ボタンぶんパネルの縦位置が下がる（`maxHeight` を詰める）。開いている間ボタンとパネルヘッダに閉じ手段が2つ（ボタン/×）並ぶが、役割が同じ（閉じる）で混乱にならない。
- **正の更新**：`DESIGN`§2／`docs/05`§3／`docs/99`（確定索引「絞り込みパネルの構え」＋実装スライス 4c）。`ADR-0029` に「配置・開閉の一部を ADR-0031 で更新」の注記。
- **撤回（ADR-0029 から）**：「開いている間はトグルボタンを隠す」「閉じる手段＝X と ESC のみ」。
- **影響なし**：`ADR-0028`（絞り込み=ハイライト→カルテ）・データ/ロジック（`filtering.ts`）・カルテ。器だけの変更。
- **スライス**：4c（#69）の継続（PR #70 を更新）。新スライスは立てない。
