# ADR-0026: 交通（駅）の地図表現を駅点ベースへ（市区町村面塗りを取りやめ）
- ステータス: 承認
- 日付: 2026-06-26
- 関連: `ADR-0007`（利便/交通＝両用＝「色分け=合計乗降客数」を本ADRで撤回）／`ADR-0005`（指標化・面塗りの前提を精緻化）／`ADR-0010`（教育＝点件数は色分けしない＝同型の判断）／`ADR-0016`（重ね/塗り絵＝生レイヤー）／実装 `feature/station-passengers-slice`（②b・**マージしない**）

## なぜ（背景・課題）
②b で「市区町村ごとの合計乗降客数」を面塗り（choropleth）で実装し、層4（実画面）で見たところ、**駅は点の現象**ゆえ市区町村に丸めると実態にそぐわないとオーナーが指摘：
- **境界の駅が一方の市区町村に恣意的に割り付く**（reviewer が独立に実証＝羽田モノレールが品川区側・京王相模原線が稲城市側に中点が落ちる等の境界誤割付）。
- 正規化なしの単純合計でハブのある区が支配し、「その街の交通利便」を映さない。
- 駅は「駅ごと」に見て初めて意味がある（どこに大きい駅があるか）。

これは既決の論理と整合する：**生活施設・教育は「点件数は誤読ゆえ色分けしない・重ねのみ」（`ADR-0010`）**。交通だけ「乗降客数は意味ある量」として両用の例外にした（`ADR-0007`）が、地図で見ると面塗りが実態を映さないと分かった。

## 結論（決定）
- **交通（駅 XKT015）の地図表現は駅点ベース**＝各駅の座標に乗降客数を紐づけて見せる（重ね/塗り絵・`ADR-0016`）。**市区町村の合計乗降客数の面塗りは採らない**（`ADR-0007` の「色分け＝合計乗降客数2023」を撤回）。
- **一般原則（指標表現の振り分けを精緻化）**：**面塗り（choropleth）は“面の現象”に限る**（面積率＝災害、地価、人口、面積など区域に属する量）。**“点の現象”（駅・施設・学校）は点／重ねで見せる**。交通は教育・生活施設と同じ「点側」へ移す。
- **具体形は未定＝`docs/99` 保留**：駅をホバーして数値表示／駅から半径圏を色付け／最寄り駅距離の利便指標 等（オーナー提示の例・確定ではない）。feature 間の兼ね合いを見て決める。最寄り駅距離のような利便指標は v1 以降の想定。
- 取得済みデータ（XKT015＝駅ごとの乗降客数＋位置）と取得スクリプト・パーサ（`scripts/fetch-xkt015.sh`・`internal/ingest/xkt015_props.go`）・偵察知見（`backend-conventions` §5.3）は、将来の**駅点オーバーレイ**スライスで再利用する。②b の「市区町村集計＋面塗り＋指標トグル」は不採用（マージしない）。

## 検討した代替案と捨てた理由
- **市区町村の合計乗降客数で面塗り（②b の形）** … 境界割付・丸めの歪み・正規化なしで実態にそぐわない → 撤回。
- **市区町村の別指標で面塗り（駅密度／人口あたり駅数／最寄り距離 等）** … 「面で比べたい」なら一応可だが、点→面の境界問題が残り、交通の価値は点で十分に出せる → 当面は採らない（必要なら将来検討）。
- **両用を維持（`ADR-0007` のまま）** … 層4 で面塗りが実態を映さないと判明 → 見直す。

## 影響（結果・トレードオフ）
- 実装スライス②b（市区町村面塗り）は**マージせずクローズ**。交通＝**駅点オーバーレイ**を将来スライスへ（重ね機構＝`ADR-0016` の塗り絵は未実装ゆえ、その実装とセット）。
- `metric_value`／値の道（面塗り）パイプライン（②a で実証）は**面の指標**（将来人口・地価・災害面積率）で継続して活きる。
- reviewer が指摘した「点→市区町村の境界跨ぎ」は、本決定（点は点で見せる）により構造的に解消。
- 「面で比べる」（`ADR-0012`）は面の現象で行う。交通は点で見る、と役割を分ける。
