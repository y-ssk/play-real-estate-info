# ADR-0010: 教育分野の指標定義 — 色分けせず重ね＋カルテ（質データが無いため位置・分布・学区まで）

- ステータス: 承認
- 日付: 2026-06-24
- 関連: `ADR-0005`（指標化の高度）/ `ADR-0007`（点データの扱い）/ `docs/99`（バックログ優先1）/ `docs/01`§3 / `docs/02`§3 / `docs/api-if-spec/XKT006・XKT007・XKT004・XKT005`

## なぜ（背景・課題）

割れる分野の「教育」を、手持ちデータで何の数値で表すかを決める。
MLITの教育データは**位置（学校・保育施設の点）と学区（通学区域のポリゴン）**は持つが、**学校の質・評判・進学実績・保育の定員/待機児童は持たない**（IF定義に記載なし）。

## 結論（決定）

1. **教育は色分け（市区町村の濃淡）をしない**。件数や密度だけで「教育が良い街」と塗ると誤読を生む（保育施設が多くても定員割れか満杯かは分からない）。＝家賃を持たないのと同じ割り切り（`docs/01`§3）。

2. **学校（XKT006）・保育施設（XKT007）＝重ね（点）＋カルテ件数**（校種ごと：小/中/高、保育/幼稚園。種別は混ぜない）。

3. **学区（小学校区 XKT004・中学校区 XKT005）＝重ね（学区の境界線）＋カルテ（その街/地点の対応学校名）**。子育て世帯に直接効く「どの学区か」。これも色分けではない。

4. **MVPは「位置・分布・学区」まで**。学校の質・進学実績・保育の定員/待機児童の比較は対象外と明記する。踏み込むには別データソースが要る（将来枠として `docs/99` 保留に登録）。

## 検討した代替案と捨てた理由

- **学校数・保育施設数（または密度）で色分け** … 質・定員が不明なため件数の多寡が「良さ」を意味せず誤読を招く。色分けしない。
- **学区を市区町村集計にする** … 学区は市区町村内の細分でカテゴリ境界。集計値になじまない。重ね＋カルテで扱う。
- **質指標を独自に作る** … 元データに無い。憶測で作れば事実ベース（`ADR-0005`）に反する。別データソースの導入を将来検討。

## 影響（結果・トレードオフ）

- XKT006/007 は点・タイル取得（市区町村コードでの直接取得は不可。`P29_001`/`administrativeAreaCode` で集計）。校種は `P29_003`/`schoolClassCode`（凡例インライン）で区別。公立/私立や定員は凡例/データが無く判定困難。XKT007 は幼稚園系/保育系で2系統フィールド → 取り込みで正規化が必要。
- XKT004/005 は学区ポリゴン。対応学校名（`A27_004_ja`/`A32_004_ja`）・学校コード（先頭 B=小/C=中）を持ち、学校点（XKT006）と結合できる可能性。公立学区のみ（未整備自治体は空）。
- 教育の集計（学校数等）も `ADR-0006` の共通形に乗るが、本分野は色分けを持たないため集計の主役は件数（カルテ）。
- **ブロック2（各分野の指標：災害・利便・相場・将来・教育）完了**。残ブロック：カルテの中身（ブロック3）、比較体験（ブロック4）。
