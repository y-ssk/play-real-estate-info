# ADR-0019: ベースマップ＝MVPは地理院地図(GSI)淡色・将来Protomaps自前ホスト・トークンサービスは捨てる

- ステータス: 承認
- 日付: 2026-06-25
- 関連: `docs/99_decision-register.md`（優先3 受け渡し仕様・3-4 ベースマップ）／`docs/02_architecture.md` §7フロント・§1タイルプロキシ／`ADR-0013`（MapLibre・トークン不要＝透明性）／`ADR-0011`（出典表示）／`ADR-0014`（配信3857）／学習メモ `docs/notes/2026-06-25-basemap.md`

## なぜ（背景・課題）
MapLibre にはデータ層（面塗り・重ね）の下に敷く背景地図（下地）が要る。`ADR-0013` の「トークン不要＝透明性／ベクタでメッシュに強い」を効かせ、MLIT・国土数値情報のデータ生態系と整合する下地を選ぶ。下地は「本丸厚く・周辺薄く」の周辺。

## 結論（決定）
- **MVP＝地理院地図（GSI）の淡色地図ラスタタイル**を、**自前の style（地図定義JSON）にラスタ source として1枚敷く**。その上に我々のデータ層（ベクタ＝GeoJSON→MVT）を重ねる（layers 配列の順＝重なり順）。
  - **トークン不要・公式・日本語・ops不要**＝MVP最薄。外部 style URL に依存しない（自前 style＝透明）。
  - **出典「国土地理院」を自動表示**（MapLibre の AttributionControl が source の `attribution` を表示）＝`ADR-0011` の出典規律と同じ枠。
  - **座標系は Web メルカトル(3857)** で配信3857（`ADR-0014`）と一致。MapLibre 側で吸収不要。
  - **MVP は直アクセス**（style に GSI タイルURLを書く）→ 将来キャッシュ/規約対応で **Go プロキシ**（`/tiles/base/...`→GSI・`docs/02` §1 の器）へ切替可（style の URL 差し替えだけ＝可逆）。
- **将来＝Protomaps PMTiles 自前ホスト（案C）へ昇格可**：DESIGN のスレート配色に合わせたベクタ下地／完全独立が要るとき。単一ファイルを Go が配信（一体型・タイルプロキシの思想に最も合う）。可逆。

## 検討した代替案と捨てた理由
- **B. 外部ベクタタイルサービス**（MapTiler/Stadia 等）… 綺麗なベクタ下地が即手に入るが、**要APIキー・外部依存・利用制限・ToS**。`ADR-0013` の「トークン不要・透明性」と衝突するため**捨てる**（見栄え優先の最終手段）。
- **C. 自前ホスト（Protomaps PMTiles）を MVP から**… 透明・一体型に最も合うが、地域抽出ファイルの用意＋スタイル自作＋pmtiles 読み込みプラグインで**MVPには過剰**。将来枠（昇格先）として保持。
- **D. OSM 生ラスタ直**（`tile.openstreetmap.org`）… 本番利用ポリシー違反で**不可**。

## 影響（結果・トレードオフ）
- **優先3（受け渡し仕様＆FE詳細）が完全に確定**（3-1〜3-4 すべて決着）。
- 出典表示に「国土地理院」を追加（`ADR-0011` 枠）。
- **実装着手時に公式で最終確認**（憶測しない）：GSI タイルの正確なURL・最大ズーム・利用規約（大量/継続アクセス・プロキシ/キャッシュの可否）。
- 下地がラスタでも、データ層はベクタのまま重ねられる＝メッシュ戦略（`ADR-0015`）と矛盾しない。
- 実装コード（style 定義・data 層追加・出典）は FE実装／ETL 縦スライスで書く。本ADRは調達先と導入形の確定。
