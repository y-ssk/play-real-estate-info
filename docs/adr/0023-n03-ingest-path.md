# ADR-0023: N03投入経路＝使い捨て別コンテナ（GDAL公式イメージ・ogr2ogr）
- ステータス: 承認
- 日付: 2026-06-25
- 関連: `ADR-0022`（投入機構＝ハイブリッド。本ADRはその保留点「ローダ binary の調達・実行経路」を確定）／**お作法の最新は `docs/backend-conventions.md` §5**（本ADRは凍結記録）／`ADR-0014`（N03採用・SRID6668・5桁コード）／`ADR-0015`（マテリアライズ・継ぎ目）／`ADR-0013`（PostGISコンテナ・攻撃面最小の軸）／`docs/99_decision-register.md`（保留「N03 投入経路の確定」→確定）／学習メモ `docs/notes/2026-06-25-n03-ingest-path.md`

## なぜ（背景・課題）
`ADR-0022` で投入機構＝ハイブリッド（投入＝外部ローダ／正規化＝SQL・Go）は決めたが、**ローダ binary をどこから持ってきて、どこで実行するか**は未決のまま `docs/99` に預けていた。段0 の実機確認で **`postgis/postgis:16-3.4` には `shp2pgsql`/`ogr2ogr` がどちらも非同梱**（拡張＋SQLスクリプトのみ・ローダ binary は別パッケージ）と判明し、「ゼロ追加で `shp2pgsql` を使う」前提が崩れた。段1（N03 投入）着手にあたり、この調達・実行経路を確定する。

## 結論（決定）
- **置き場所＝使い捨ての別コンテナ（案A）**。投入する時だけ GDAL 公式イメージ `ghcr.io/osgeo/gdal` から `docker run --rm` でコンテナを起動し、compose と同一ネットワーク越しに DB コンテナへ流し込み、**終了後に破棄**する。**DB イメージ（`postgis/postgis`）は公式のまま改変しない**。
- **ローダ＝`ogr2ogr`（GDAL）**。GDAL 公式イメージに同梱で入手・保守が素直。N03 はシェープゆえ機能的に十分（`ADR-0022` の「形式都合で `ogr2ogr` へ寄せるのは可逆」の範囲内）。
- **正規化（5桁コード化・年度固定・値域チェック＝本丸）は従来どおり SQL・Go**。投入ツールの差し替えに不変（`ADR-0022`/`ADR-0015` の継ぎ目）。
- 投入ツールは serving（一体型）バイナリに入らない**データ投入時の道具**＝実行時の攻撃面とは別レイヤー。案A はそれを実行環境のレベルでも体現する（DB にも端末にも道具を残さない）。

## 検討した代替案と捨てた理由
- **案B：DB イメージにローダを焼き込んで同居**（`FROM postgis/postgis` ＋ `apt install gdal-bin` のカスタム build）… DB（永続層）に年1回しか使わない投入道具を常駐させる＝**サイズ増・攻撃面増・公式イメージからの乖離で再現性低下**。`ADR-0013`/`0020`/`0021` で一貫して採ってきた「攻撃面最小・薄く保つ」軸と反する。localhost 接続の楽さは代償に見合わない。
- **案C：端末（WSL）に直接インストール** … 環境再現性ゼロ・Docker 前提と不整合・READMEに手順が増える＝却下。
- **ローダに `shp2pgsql` を選ぶ** … 単体が入った定番の既製イメージが乏しく自作の手間が要る。N03 はシェープのみゆえ `ogr2ogr` で十分。将来 `shp2pgsql` 固有の事情が出れば再考（継ぎ目ゆえ可逆）。

## 影響（結果・トレードオフ）
- お作法（取り決め）＝`backend-conventions` §5 を本決定で更新（案A の手順・`ogr2ogr`・接続/マウント設定・破棄）。
- **代償**＝案A はネットワーク（compose 同一ネットワークへの参加）とファイルの見せ方（ボリュームマウント）を一度だけ設定する手間がある。投入が localhost で完結する案B より初期設定が一手間。
- **実装時に実物で確認**（憶測しない・`docs/ai-feedback.md` F-001）：GDAL 公式イメージに `ogr2ogr` 同梱（`docker run --rm ghcr.io/osgeo/gdal ogr2ogr --version`）・N03 実ファイルの `.prj`（座標系→6668 変換要否）・`.dbf`（文字コード CP932 か）。
- **可逆**：継ぎ目ゆえローダ/イメージの差し替えは工程3（投入）に限局し、正規化以降（本丸）に波及しない。
