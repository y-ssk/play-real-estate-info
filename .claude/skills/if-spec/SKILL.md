# MLIT IF定義 構造化（コピペ → フォーマット）

ユーザーが貼った MLIT API の生コピペ（公式ページの IF 定義）を、テンプレートの形に構造化して書き出す。
**ユーザーは「コピペを貼って起動するだけ」。ファイルの作成・配置はこのスキルが行う。**

## 入力
- ユーザーが直前に貼った生コピペ（`$ARGUMENTS`、または同じ/直前のメッセージ本文）。整形されていない原文でよい。
- 生コピペが見当たらなければ「公式の IF 定義を貼ってください」と促す（憶測で進めない）。

## 手順
1. `docs/api-if-spec/_TEMPLATE.md` を読み、最新のテンプレ構造に従う。
2. 生コピペから API ID（例: `XIT002`）を判別する。判別できなければユーザーに確認する。
3. テンプレの各セクション（1.概要 / URL / 2.パラメータ / 3.レスポンス / 4.使用例）へ**原文を転記**する。
   - **転記のみ。憶測で補わない。** 原文に無い項目は「未確認」と明記。
   - 表記ゆれ・矛盾（例: パラメータ名の不一致）は勝手に直さず「要確認」として残す。
   - セクション5（MachiLens 取り込み観点）は空欄プレースホルダのまま（実装着手時に埋める）。
4. `docs/api-if-spec/<ID>.md` に書き出す（既存があれば一言断ってから上書き）。
5. 「未確認・要確認」に挙げた項目だけを、ユーザーへ短く報告する。

## 禁止
- 原文に無い仕様の捏造。
- 秘匿情報（APIキー）への言及・記入。

> これは「手順（実行）」。なぜ md で持つか等の決定の経緯は `docs/adr/0002-if-spec-as-readable-reference.md`。
