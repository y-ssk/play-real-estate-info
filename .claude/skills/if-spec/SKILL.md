# MLIT IF定義 構造化（コピペ → フォーマット）

ユーザーが貼った MLIT API の生コピペ（公式ページの IF 定義）を、テンプレートの形に構造化して書き出す。
**ユーザーは「コピペを貼って起動するだけ」。ファイルの作成・配置はこのスキルが行う。**

## 入力（チャット貼り付けは使わない）
- 入力元は **`docs/api-if-spec/_paste.md`**（gitignore 対象の貼り付け用インボックス）。
  - `API_ID:` 欄 … 任意。空なら本文から判別し、判別不能ならユーザーに確認。
  - `--- PASTE BELOW THIS LINE ---` 以降 … 公式 IF 定義の生コピペ（整形不要）。
- `_paste.md` が無ければ作成し、本文が空なら「`_paste.md` に貼って再実行してください」と促す（憶測で進めない）。
> チャットへの直接貼り付けは読み取り元にしない（大きな貼り付けは `[Pasted text #N]` に置換され正確に読めないため）。

## 手順
1. `docs/api-if-spec/_paste.md` を読み、`API_ID` と貼り付け本文を取り出す。
2. `docs/api-if-spec/_TEMPLATE.md` を読み、最新のテンプレ構造に従う。ID が空なら本文から判別（不能なら確認）。
3. テンプレの各セクション（1.概要 / URL / 2.パラメータ / 3.レスポンス / 4.使用例）へ**原文を転記**する。
   - **転記のみ。憶測で補わない。** 原文に無い項目は「未確認」と明記。
   - 表記ゆれ・矛盾（例: パラメータ名の不一致）は勝手に直さず「要確認」として残す。
   - セクション5（MachiLens 取り込み観点）は空欄プレースホルダのまま（実装着手時に埋める）。
4. `docs/api-if-spec/<ID>.md` に書き出す（既存があれば一言断ってから上書き）。
5. **`_paste.md` を空の初期状態に戻す**（`API_ID:` 空・貼り付け本文を削除）。次回そのまま再利用できる状態にする。
6. 「未確認・要確認」に挙げた項目だけを、ユーザーへ短く報告する。

## 禁止
- 原文に無い仕様の捏造。
- 秘匿情報（APIキー）への言及・記入。

> これは「手順（実行）」。なぜ md で持つか等の決定の経緯は `docs/adr/0002-if-spec-as-readable-reference.md`。
